## 자료형

자주 쓰는 기본 자료형
- int : 4바이트
- float : 4바이트
- double : 8바이트
- bool : 1바이트
- char : 2바이트 ( utf-16 한정 영문-한글 상관 없이 2바이트 )

---- 크기에 따라 표현 범위를 조절해야 할때 ----
- short : 2바이트
- long : 8바이트

--- 음수 값을 사용 못함 & 양수 표현범위 두배 ( unsigned ) -----------
- byte : 1바이트
- ushort : 2바이트
- uint : 4바이트
- ulong : 8바이트
- **string : 참조형**

TIP
- Enum : 크기 제한하기 위해 byte 쓰면 좋음

## IF문

```
int gold = 100;

if ( gold >= 100 )
{

}

else
{

}

```

해당 상황은 **조건에 따른 선택**이다.

Gold가 100 이상이라면 if문을 실행, 미만이라면 else문을 실행

if문을 실행한다면 else문은 아예 검토되거나 실행되지 않는다.

```
for (int idx = 0 ; idx < 10 ; idx++)
{
	for (int jdx = 0 ; jdx < 5 ; jdx++)
	{
		if(jdx == 2)
		{
			break;
		}
	}
}
```

해당 코드는 이중for문의 예시이다.

idx = 0 상태에서 jdx 0 부터 4 까지 비교
이후 idx = 1 상태에서 jdx 0 부터 4까지 비교
이를 idx = 9 까지 반복한다.

**BUT IF (jdx == 2){ break; } 문이 존재한다.
이를 통해 idx == 0 이라 가정하고,
jdx == 2 일때 jdx를 사용하는 for문이 중단된다.
이후 idx == 1로 변환 된 뒤 다시 반복된다.
