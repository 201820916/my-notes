## 자료구조

- Data Struct
- 단순한 데이터 쌓기 X
- 검색, 추가, 삭제 등 특정 목적 수행
- 데이터 사이 관계 정의
- 즉, 수많은 양의 데이터를 효율적으로 관리하기 위해서 필요한 개념
- Why? -> 자원은 한정되어 있고 데이터는 무수히 많기 때문에

자료구조의 3가지 특징
- 효율성 : 적절한 자료구조 선택 -> 프로그램의 속도 향상
- 추상화 : 복잡한 데이터의 논리적 단순화 -> 쉬운 이해
- 재사용성 : 다양한 프로그램에서 반복 사용 가능

## 선형/비선형 자료구조

### 선형(Linear Data)

- 배열
- 연결 리스트
- 스택
- 큐

특징 - 연속적, 데이터가 일렬로 정렬
### 비선형(Non-Linear Data)
- 트리
- 그래프
- 힙

특징 - 데이터의 계층화, 순차적이지 않은 데이터 구성

## BIG-O 표기법

- 데이터 양이 늘어나면 -> 연산 횟수, 메모리 사용량 증가 -> 얼마나 급격하게 변화하는가 설명
- 객관성 : 하드웨어를 불문하고 알고리즘 자체의 효율성 평가
- 최악 대비 : 최악의 케이스를 가정하고 **이정도의 성능은 보장된다**를 설명
- 확장성 예측 : 데이터의 수에 따른 연산 부하를 미리 예측 가능

## 박싱 / 언박싱

### 박싱
- 값 타입(스택에 저장)- > 참조 타입(힙에 저장)으로 변환하는 과정
- int, float, struct 등의 값을 object로 변환할 때 일어남
- 스택 메모리에 있던 값 타입 데이터가 힙 메모리 영역에 새롭게 할닫ㅇ
- 스택에는 힙 메모리를 가리키는 참조가 남음
- 특징 : 암시적 변환

```
int i = 123;
object o = i;
```

### 언박싱

- 반대로 참조타입(힙메모리) -> 다시 원래의 값 타입(스택메모리)로 되돌리는 과정
- 힙 영역에 저장된 객체에서 값을 꺼내옴
- 스택 영역의 값 타입 변수에 복사
- **정확히 일치하는 타입으로 명시적 캐스팅 필요**
-
```
object o = 123; // 박싱 
int j = (int) o; // 언박싱 (명시적 캐스팅 필수)
```


**MEMO**

- 딩연하지만 값형 - 값형 대입, 참조형 - 참조형 대입은 박싱/언박싱이 아님
- **태생부터 구분되는 자료형**을 인지하고 형 변환시 박싱-언박싱 발생

## Static

- 클래스 자체에 소속되도록 지정
- New로 객체 생성하지 않아도 클래스명.멤버명 형식으로 직접 접근
- `static` 멤버는 클래스당 **딱 하나만 존재**하여 모든 인스턴스가 공유
- Public **static** void Main(string[] args)

### 스태틱 필드
```
class Player 
{ 
	public static int TotalCount = 0; // 모든 플레이어가 공유 public string Name; 
	
	public Player(string name) 
	{ 
		Name = name; TotalCount++; // 인스턴스가 생성될 때마다 공통 카운터 증가 
	} 
} 
// 사용 
Player p1 = new Player("홍길동"); 
Player p2 = new Player("이순신"); 
Console.WriteLine(Player.TotalCount); // 2
```

### 스태틱 메서드

인스턴스 생성 없이 호출 가능하며, `클래스명.메서드명()` 형식으로 사용

**static 메서드 내부에서는 non-static 인스턴스 멤버에 접근할 수 없음**
- 어떤 인스턴스 데이터를 가리킬지 알 수 없음

```
public class MathHelper 
{ 
	public static int Add(int a, int b) => a + b; 
} 

int result = MathHelper.Add(3, 5); // 객체 생성 없이 바로 호출
```

### 스태틱 클래스

- 모든 멤버가 static이여야 하며, new로 인스턴스화 불가능
- 주로 유틸리티/헬퍼 함수 모음에 사용
```
public static class GameUtils 
{ 
	public static float Lerp(float a, float b, float t) => a + (b - a) * t; 
	
	public static int Clamp(int val, int min, int max) => Math.Max(min, Math.Min(max, val)); 
}
```

### static 생성자

- 클래스가 처음 사용되는 시점에 딱 한번 자동으로 호출
- 접근제한자를 붙일 수 없고, 매개변수도 가질 수 없습니다.

```
public class Config 
{ 
	public static string ServerUrl; static Config() 
	{ 
	// static 생성자 ServerUrl = "https://game.server.com"; 
	} 
}
```
