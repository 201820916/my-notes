
## Main() 함수

- 프로그램 시작점

```
int main()
{

  [생략]
  
  return 0;
}
```

- int -> 반환 형
- { } -> 실행 범위
- return 0 -> 반환 값, 정상 종료

반환 형은 필요에 따라 선택 할 수 있다.

```
void FuctionNameA()
{
	cout << "FunctionNameA" << endl;
}
```

- void -> 반환형
- void는 반환 값이 없다.

```
bool FuncA(int candyId) 
{ 
	bool isA = (candyId == 10) ? true : false; return isA;
} 

void FuncB(bool isMyCandy) 
{ 
	if (isMyCandy) 
	{ 
		std::cout << "정답" << std::endl; 
	} 
} 

int main()
{ 
	bool myCandy = FuncA(10); FuncB(myCandy); 
	
	return 0; 
}
```


기능을 개별 함수로 구현하여 직관성을 얻을 수 있다.

## 변수

- 값을 담는 그릇
- 단, 그릇과 값의 타입이 동일해야 함.
```
int result = 95;
string Gamename = "Overwatch"
```

- 자료형 : int, string
- 변수명 : result, Gamename

### 지역 변수와 전역 변수

#### 메모리의 4영역

코드 - 데이터 - 힙 - 스택

```
int m_PandaBirthDay;

void TemporalFuction()
{
	m_PandaBirthDay = 1990;
	
	int pandaAge = 4;
	pandaAge = 5;
}

```

int m_PandaBirthDay; -> 전역변수, 데이터 영역 저장
- 프로그램 시작과 동시에 메모리 공간이 할당
- 프로그램 종료까지 살아있음
- 함수에서 해당 변수에 접근 가능

int pandaAge = 4; -> 지역변수
- 함수가 시작되면 메모리 할당
- 함수 종료까지 살아있음
- 다른 함수가 해당 변수에 접근 불가능

## STACK 메모리

- 임시 데이터들을 **차곡차곡** 쌓아두는 공간
- 저장되는 데이터 : 매개변수, 지역변수, 값 타입 데이터
- 동작 방석 : 후입선출(LIFO), 데이터 삽입(Push), 데이터 삭제(POP)
- 특징 : 메모리 할당과 해제가 컴파일러에 의해 빠른 속도로 자동 수행됨, 크기 제한으로 큰 데이터는 불가능

### HEAP 메모리

- 크기가 크거나 유동적인 데이터를 저장하기 위한 넓은 메모리 공간
- 저장 데이터 : C#의 참조 타입 - class 객체, string, 배열 등
- 동작 방식 : 개발자가 원할때(new 키워드 등) 필요한 만큼 동적 메모리 할당
- 특징 : 메모리 크기 제한 X, 할당/해제 자동이지만 느림 

#### 가비지 컬렉터

사용 과정

1. 가정 : 힙 메모리에 있는 모든 데이터를 쓰레기로 가정
2. 연결 및 사용중인 데이터를 추적하여 "사용중" 마킹
3. 표시가 되지 않는 나머지 데이터들을 삭제
4. 삭제 된 뒤 비어있는 공간을 전부 한쪽으로 밀어서 압축
5. 빈 공간 확보
