
# 행동트리

- 게임 인공지능의 행동을 설계할 때 가장 널리 쓰이는 핵심 디자인 패턴(구조)
- FSM(유한 상태 머신)의 복잡성을 해결하고 재사용성과 확장성을 극대화
- 기본적으로 **트리구조**이며 부모노드와 자식 노드를 제어하는 하향식(탑다운) 평가 방식 작동 



## FSM과 행동트리의 차이



## BT의 노드 종류

- Leaf
- Composite
- Decorate

### Composite(합성) 노드

특징
- 자식 노드가 여러개
- 어떤 방식으로 실행할 지 결정하는 제어문 역할

- 셀렉터(Selector / Composite OR 연산)
	- 자식 노드들을 왼쪽 -> 오른쪽으로 순서대로 실행
	- 자식 중 하나라도 성공하면 즉시 멈춤 + 부모에게 성공 반환

- 시퀀스 (Sequence / Composite AND 연산)
	- 자식 노드들을 왼쪽 -> 오른쪽으로 순서대로 실행
	- 자식 중 하나라도 "실패"하면 즉시 실행을 멈추고 부모에게 "실패 반환"
	- 모든 자식이 성공해야 "성공"이 반환됨

### 장식(Decorator) 노드 

특징
- 자식이 1개
- 디자인 패턴 중 데코레이터 패턴의 개념과 작동 방식 채용

데코레이터 노드
- 단 하나의 자식 노드만 가질 수 있으며, 자식 노드의 실행 여부를 필터링하거나 결과를 변형
- 조건 (Conditional) : 특정 조건 만족 시 자식 실행
- 인버터(Inverter) : 자식의 결과를 반전
- 반복(Repeater) : 자식 노드를 특정 횟수나 조건만큼 반복

#### 데코레이터 패턴

기존 객체의 코드를 수정하지 않고 기능을 동적으로 추가하는 구조적 디자인 패턴

````
public interface ICoffee  
{  
string Description();  
int Cost();  
}  
  
// ConcreteComponent  
public class BasicCoffee : ICoffee  
{  
public string Description() => "기본 커피";  
public int Cost() => 3000;  
}  
  
// Decorator  
public abstract class CoffeeDecorator : ICoffee  
{  
protected ICoffee coffee;  
  
public CoffeeDecorator(ICoffee coffee)  
{  
this.coffee = coffee;  
}  
  
public abstract string Description();  
public abstract int Cost();  
}  
  
// ConcreteDecorator  
public class MilkDecorator : CoffeeDecorator  
{  
public MilkDecorator(ICoffee coffee) : base(coffee) { }  
  
public override string Description()  
=> coffee.Description() + " + 우유";  
  
public override int Cost()  
=> coffee.Cost() + 500;  
}  
  
public class ShotDecorator : CoffeeDecorator  
{  
public ShotDecorator(ICoffee coffee) : base(coffee) { }  
  
public override string Description()  
=> coffee.Description() + " + 샷";  
  
public override int Cost()  
=> coffee.Cost() + 700;  
}  
  
// 사용  
class Program  
{  
static void Main()  
{  
ICoffee coffee = new BasicCoffee();  
  
coffee = new MilkDecorator(coffee);  
coffee = new ShotDecorator(coffee);  
  
Console.WriteLine(coffee.Description());  
Console.WriteLine($"{coffee.Cost()}원");  
}  
}

````


### Leaf 노드 : 자식이 0개

- 나뭇잎을 뜻하는 Leaf를 의미하는 노드로 자식이 없음
- 트리의 가장 끝에 위치하며 "실제로 AI가 수행하는 로직"이 담겨짐

- Action : AI가 실제로 행하는 물리적, 논리적 변화 ( Running을 자주 반환 )
	- 시간이 걸리는 작업 : 적에게 이동, 공격 애니메이션 재생 같은 실행중인 상태가 있음
	- 시간이 걸리지 않는 작업 (원샷 액션) : 상태나 데이터를 실제로 변경, 이벤트 발생, 즉시 처리가능한 게임 로직

- 조건(Condition) : AI 상태나 주변 환경을 체크 후 즉시 성공, 실패 반환
	- **조건 체크만**하기 때문에 Running이 반환되지 않음

## BT - TaskType

### 시퀀스

- **위 작업들이 모두 성공해야 전체 성공**으로 간주
- 하나라도 실패 시 즉시 실패 반환
- 하위 작업이 완료 시 다음 하위 작업을 실행
- 모든 하위 작업들이 성공하면 시퀀스 노드의 작업은 최종성공

#### 시퀀스 TASK

순차적인 일에 사용하기 좋음

- 적 NPC의 순찰
	- NPC가 특정 경로를 따라 순찰할 때, 각 지점을 차례대로 이동해야 하므로
- 퀘스트 진행
	- 플레이어가 퀘스트 수행 시 각 단계를 순서대로 완료해야 함
	- Ex. 아이템 수집 -> NPC 대화 -> 특정 장소 이동
- 복잡한 공격 패턴 (성공 콤보)
	- 첫번째 공격 성공 후 두번째 공격이 이뤄져야하는 경우
- AI 캐릭터
	- 농사 짓기 (밭 갈기 -> 씨앗 심기 -> 물 주기 -> 수확)
- 몬스터의 경비 행동
	- 경비구역 점검 -> 경로 순찰 -> 돌아와서 다시 점검
- 캐릭터의 복잡한 동작 수행
	- 물체 집고 -> 다른 위치로 옮기고 -> 내려놓는 경우
- 퍼즐
	- 스위치 당겨야만 -> 문이 열리고 -> 방으로 들어갈 수 있는

### 셀렉터

- **여러 하위 작업 중 하나라도 성공 하면 전체 성공**으로 간주
- 하위 작업 중 하나라도 성공 반환 시, 셀렉터 Task는 즉시 성공 반환
- 하위 작업이 실패 시 -> 다음 하위 작업 진행
- 모든 하위 작업 실패 시 -> 셀렉터 Task는 실패 반환


#### 셀렉터 TASK

무언가 다양한 행동 중 하나를 선택해 수행할 때

- 적 NPC의 다양한 행동
	- 여러 행동 중 하나를 선택하는 경우
	- Ex. 플레이어가 가까이 있다면 공격하고 , 멀리 있다면 도망가고
- 상황에 따른 반응
	- AI가 주변 환경이나 상태에 따른 반응을 보여주는 경우
	- Ex. 체력이 낮으면 도망 / 체력이 높으면 공격

- 플레이어 행동에 따른 반응
	- 플레이어가 대화를 시도하면 NPC는 대화
	- 플레이어가 공격하면 NPC는 전투모드 진입 후 반격

- 우선순위에 따른 행동 결정
	- 특정 행동 실패 시 다른 행동을 해야하는 경우
	- Ex. 캐릭터가 문이 잠겨 있으면 창문을 통해 들어가는 경우

- 아이템 사용
	- 문제 풀이를 위해 여러 도구 중 하나를 사용하려고 시도할 때

- 다양한 이동경로 탐색
	- 특정 지점으로 가기 위해 다양한 경로 중 1개를 선택해야 할 때


### 페러렐

- **모든 하위 작업을 동시에 실행**
- 하위 작업 중 **하나라도 실패하면 Parrallel Task는 모든 하위 작업을 종료하고 실패를 반환**
- 모든 하위 작업들이 성공 시 Parrallel Task는 성공 반환


#### 페러렐 TASK

무언가 다양한 행동들을 동시에 진행해야 할 때

- 동시 실행되는 스킬
	- 보스 몬스터가 물리 공격과 동시에 광역 메테오를 사용하는 경우
	- 플레이어가 평타 공격 시, 펫에게 동시에 스킬 공격을 명령하는 경우
- 캐릭터의 이동과 공격 동시 진행 시
	- 린검사 -> 이동하면서 검 휘두르기
	- 달리면서 총쏘기
- 동시에 수행되는 NPC 행동
	- 경비병이 순찰과 동시에 주변 경비병에게 무전을 보내야 할 때
- AI 협력 행동
	- 하나의 AI 캐릭터가 문을 열면, 다른 AI 캐릭터들은 주변을 감시하거나 , 함정, 채집 등의 상호작용을 진행해야 할 때
