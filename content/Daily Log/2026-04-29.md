
## 레이아웃

- 한정된 공간 안에 요소들을 **어디에, 어떤 크기로, 어떤 순서로 시각화**할 것인가에 대한 설계도
- UI계층 구조(하이어라키)와 UI요소 간 간격, 해상도 대응을 위한 구성을 모두 포괄하는 개념

- UI에서 뎁스는 버튼 클릭의 우선순위를 제어하기도 한다.

## UGUI

Unity GUI = UGUI

- 4.x 이전의 Legacy GUI ( OnGUI ) 를 대체한 새로운 시스템
- 버튼
- 텍스트
- 이미지
- 체력바
- 인벤토리
- 팝업창

### 시각용 컴포넌트

- image : 가장 많이 쓰는 컴포넌트
	- Sprite 출력, Simple, Sliced(나인 슬라이스 리소스), Tiled, Filled 등의 연출 지원
	- 이미지를 UI에 표시한다 -> 사용

- Raw Image : Texture 그대로 출력
	- 렌더 텍스쳐, 웹 이미지, 고해상도 이미지
	- 특수 상황에서만 사용 권장

- Text(레거시)/TextMeshPro : 글자 표현이 필요한 모든 곳에서 사용
	- TextMeshPro는 성능과 가독성 월등 

- Mask / Rect Mask 2D : 자식 요소가 부모 영역 밖으로 나갔을 때 보이지 않도록 방지
	- RectMask2D >> Mask


### 배치&구조 컴포넌트

- RectTransform : 모든 UGUI 오브젝트의 기본 컴포넌트
	- Anchor와 Pivot을 통한 해상도 대응의 핵심

- Canvas : UI가 그려지는 가장 최상위 존재
	- UI의 모든 요소들은 반드시 Canvas의 자식이여야 함.
	- UI의 좌표계 역할과 이벤트 전달 통로 역할
	- Canvas의 남용은 안됨
	- 자주 갱신되는 UI는 특정 Canvas에 묶고 나머지 정적인 UI들은 하나의 Canvas에 분리

- Layout Group : 수평, 수직, 그리드로 자식 오브젝트를 자동정렬
	- 편한 관리법
	- 동적 요소 들을 그룹 내에서 관리
