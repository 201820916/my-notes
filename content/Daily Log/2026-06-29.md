
# 3D 아트

## 툴

- 게임 개발자가 직접 이것을 다루지는 않음
- 자신이 모르는 분야다 보니 업무 분야가 한정 될 수 있음
	- 개념에 간략히 인지만 하고 있어도 도전 가능한 업무 분야가 넓어짐
	- 추후 활동 범위를 넓혀갈 수 있음
- 대표적인 툴
	- 국내 - 3Ds Max
	- 북미권 - 3Ds Max & Maya
		- Maya : 영화, 애니메이션, TV 계열에서 더 선호도가 높음
	- 인디&중소 - 블렌더


## 특수 툴

- ZBrush
	- 하이폴리곤 스컬프팅으로는 제일 유명한 툴
	- 극 실사나 하이폴 서브컬쳐 -> 지브러시 작업 -> 3Ds Max에서 최적화
	- Substance 3D Painter
		- 텍스쳐링(디퓨즈, 베이스 맵) 할때 3D 위에 바로 색칠을 하면 
			- UV에 바로바로 색이 칠해지는 3D 포톳햡 같은 프로그램
	- 이펙터
		- 과거에는 따로 썼음
			- 요즘은 포토샵으로 파티클 텍스쳐를 만듬
				- 유니티 OR 언리얼로 가져와 엔진 시스템을 통해서 이펙트 제작
				- 이펙트에 여전히 3D 모델링이나 애니메이션이 필요한 경우 3D 툴 사용


## 블렌더

- 완전 무료 프로그램
- 초창기 기능 미비 but 오픈 소스 + 라이선스 자유
	- 4.0 기준 다룬 툴 기능 대체 가능
	- 복합적 기능을 하나로 이용
	- 스타터 툴로는 대체 불가
- BUT 한국 개발사에서는 3Ds Max나 ZBrush같은 유료툴 채택률 높음

## 블렌더 - 모드

- Object 모드 : 오브젝트의 이동/회전/크기조절/복사/전체 선택 등 배치에 집중
	- 3D 그래픽스의 월드 스페이스
	
- Edit 모드 : 메쉬 단위의 제어(버텍스, 엣지, 면을 직접 수정해 "형태"를 창조)
	- 3D 그래픽스의 로컬 스페이스
	
- Sculpt 모드 : 표면 질감 제어 
	- (폴리곤 밀도가 높은 상태에서 브러쉬로 조각해 Zbrush 같은 역할)
	- 3D 그래픽스의 노말맵
	
- Weight Paint 모드 : 애니메이션 영향력 모드 
	- (뼈대가 메쉬의 어떤 부분을 얼마나 움직일지 영역을 지정) 
		- 3D 그래픽스의 본과 리깅
		
-  Texture Paint 모드 : 메쉬 표면에 직접 색을 입히는 모드 
	- (서브스턴스 페인터(Substance 3D) 툴 역할) = 3D 그래픽스의 디퓨즈맵 (베이스 컬러)
