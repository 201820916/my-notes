### MEMO : 포트폴리오

- 제출받은 포트폴리오 스캔 -> 인사팀의 시간이 모자랄 수 있음
- Git 주소를 입력 시 인사팀의 시간 단축
	- 내 포폴이 패싱당하지 않을 가능성 UP
	- 제대로 된 평가 받기 가능

### Git 용어

- 레포지토리, 레포 - 작업소
- 클론 - 외부의 레포를 로컬에 복제
- 로컬 브랜치 / 리모트 브랜치
	- 로컬 - 내 PC 범위(저장공간 한정)
		- 커밋은 100mb 내로 조절해서 진행
		- 타인은 로컬 레포의 내용을 볼 수 없음
	- 리모트
- 커밋 - 로컬의 작업물을 git에 보낼 수 있는 상태로 변경
- 푸쉬 - 커밋된 작업물을 git에 보내는 작업
- 패치 - 
- 풀 - git의 작업물을 그대로 로컬에 복제
- 최신화 - Fetch하고 내가 작업하는 브랜치에 받을게 있다면 아래 화살표가 나타남.
	- 어느정도 작업을 정리하고 커밋, 또는 스태시를 떠두고 Pull 하면 됨.
- 컨플릭트 - 충돌, 커밋한 작업물과 git의 작업물이 충돌 된 경우
- 리졸브 - 충돌된 작업물 중 하나를 선택하여 커밋
- 머지 - 

### 브랜치

#### 마스터 브랜치

- 굉장히 중요한 브랜치
- Push 기능 제한 둔 경우 많음
- 개인의 브랜치를 생성해서 테스트 한 뒤에 결재
	- 내가 하려는 작업을 브랜치 이름으로 명명해서 머지 시 혼동 없도록 세팅
