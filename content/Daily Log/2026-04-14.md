

## 델리게이터


- 함수데이터
- 클래스 외부에서도 호출 및 수정 가능
- Like 공용 리모컨

## 이벤트

- 델리게이터에 특정 기능을 미리 등록
- 이벤트 발생 시 해당 코드 실행

### 이벤트 키워드

- 델리게이트 기반으로 동작
- 클래스 외부에서는 오직 += / -= 등록과 해지만 가능

#### 이벤트 구조
- 델리게이트로 구현 = 이벤트를 생성 = 콜백 구조를 생성
- **이벤트 구조를 만듭시다** -> Func나 Action 같은 델리게이트 사용하고 event 키워드 붙히기
	-  구독 - 해지의 프로그램 구조를 형성하자\
- 델리게이트 -> 자료형
- 자료형을 이용해 구조를 형성 -> 이벤트, 이벤트 발생, 이벤트 구독 같은 포괄적 단어로 사용



### 델리게이트와 이벤트의 차이

델리게이트
	- 커스텀 델리게이트
	- 내장 델리게이트 : 별도 키워드로 타입을 선언할 필요 없이 **바로 쓸 수 있게** .NET이 제공
		 - Action (반환값 없음, void)
		 - Func ( 반환값 있음 )
		 - Predicate ( 반환값 Bool 고정 )

이벤트
	- event 키워드 사용

| 구분    | 델리게이트          | 이벤트          |
| ----- | -------------- | ------------ |
| 선언 위치 | 클래스 내/외부 모두 가능 | 클래스 내부에서만 가능 |
| 외부 호출 | 가능             | 불가능          |
| 외부 할당 | 가능             | 불가능          |

| 기능       | 변수       | 이벤트         |
| -------- | -------- | ----------- |
| 구독/해지    | 가능       | 가능          |
| 덮어쓰기     | 가능(위험)   | 불가능(컴파일 에러) |
| 외부 호출    | 가능(보안취약) | 불가능(컴파일 에러) |
| 상속/인터페이스 | 불가능(필드)  | 가능(멤버)      |

## 표준 델리게이트 ( Action과 Func Predicate )

- Action
```
public Action<string, int> OnPugHappy;

OnPugHappy?.Invoke(food, 100)

// OnPugHappy에 구독된 메서드가 없으면 호출 X

OnPugHappy += TailWagAction; 
OnPugHappy += BarkAction;
// 메서드 구독


static void TailWagAction(string food, int extraCount) 
{ 
	Console.WriteLine($"[행동] {food} 냄새를 맡고 꼬리를 살랑살랑 흔듭니다."); 
} 


static void BarkAction(string food, int extraCount) 
{ 
	Console.WriteLine($"[행동] {food}을 더 달라고 멍멍! 짖습니다."); 
}


```



- Func
```
public Func<string, int, bool> OnPugHappy;

bool is PugHappy = OnPugHappy?.Invoke(food,100);

static bool TailWagAction(string food, int extraCount) 
{ 
	Console.WriteLine($"[행동] {food} 냄새를 맡고 꼬리를 살랑살랑 흔듭니다."); 
	return true; 
}

static bool BarkAction(string food, int extraCount) 
{ 
	Console.WriteLine($"[행동] {food}을 더 달라고 멍멍! 짖습니다."); 
	return true; 
}

```


## 델리게이트 활용 : 콜백 & 파라미터

- 메서드를 담은 델리게이트를 파라미터로 넘기는 것 = 콜백

호출하는 쪽 -> 메서드를 델리게이트로 포장해서 넘김
받는 쪽 -> 먼저 기능 수행 -> 적절한 타이밍에 메서드를 호출


```
using System;

class Program
{
    // ✅ 콜백을 파라미터로 받는 메서드
    static void FeedPug(string food, Action<string> callback)
    {
        Console.WriteLine($"=== {food} 를 준비합니다... ===");
        // 자기 할 일을 먼저 하고
        Console.WriteLine($"=== {food} 지급 완료! ===");

        // 적절한 타이밍에 넘겨받은 메서드(콜백) 호출
        callback(food);
    }

    // ✅ 콜백으로 넘길 메서드들
    static void Bark(string food)
    {
        Console.WriteLine($"[행동] {food} 을 더 달라고 멍멍! 짖습니다.");
    }

    static void WagTail(string food)
    {
        Console.WriteLine($"[행동] {food} 냄새를 맡고 꼬리를 살랑살랑 흔듭니다.");
    }

    static void Main()
    {
        // Bark 메서드를 Action 델리게이트에 담아서 넘김
        FeedPug("치킨", Bark);

        Console.WriteLine();

        // WagTail 메서드를 Action 델리게이트에 담아서 넘김
        FeedPug("참치", WagTail);
    }
}


```
