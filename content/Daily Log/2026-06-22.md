
# NavMesh

- 길을 찾다 = Nav(네비게이션의 Nav) + Mesh의 합성어
- 게임 월드 내에서 AI 캐릭터가 지형과 장애물을 인식
	- 최종 목적지까지 최적의 경로를 찾아갈 수 있도록 도와주는 네비게이션 + 길찾기 시스템

## 웨이포인트

- 1세대 방식
	- 미리 지정한 경로나 웨이포인트를 찍어서 해당 점들을 선으로 연결
		- 거대한 그물망 만들어서 AI 이동 경로 설정
	- 단점
		- 지정된 선 위만 다니므로 다소 딱딱해보임
		- 너무 넓은 맵은 경로/웨이포인트 설정 어려움

- 2세대 방식 : 커스텀 패스 메쉬
	- 실제 지형 매쉬 X
	- **모델러가 극 로우폴리의 지형 메쉬를 하나 더 생성**
		- 해당 버텍스나 폴리곤 지점, 경계를 활용해 A* 알고리즘 사용 -> 구현
	- 웨이포인트보다 자연스러움
		- 지형&배경 수정 시 배경 모델러에게 리소스 수정을 요청해야 함
	- 현재의 네비메쉬는 2세대의 관념과 동일하나 **모델러 없이 제작 가능하도록 (Bake) NavMesh를 사용함**

- 네비메쉬 : 캐릭터가 걸어다닐 수 있는 지형을 **단순화된 다각형** 데이터로 변환
- 베이킹 : 씬의 지형이나 오브젝트 데이터를 분석해 AI가 다닐 수 있는 네비메쉬 지도 생성
	- Like 라이트맵 베이킹
		- 베이킹 단어 사용 -> 에디터에서 미리 준비해 둬서 런타임(게임실행중)에 사용

## NavMesh 관련 컴포넌트

- 네비메쉬 표면 (NavMeshSurface) : 실질적인 네비메쉬 지도 생성 컴포넌트
	- 특정 레이어만 포함하거나, 자식 오브젝트들만 수집해 지도를 그릴 수 있음
		- 대규모 씬 맵 구조 최 적화에 유리
		
- 네비메쉬 요원 (NavMeshAgent) : 길을 찾아 움직이는 주체에 부착하는 컴포넌트
	- 회전속도, 가속도, 반경, 높이 경사각 제한 등 설정
		- 지형에 맞춰 스스로 경로를 추적 회피

- 네비메쉬 방해물(NavMeshObstacle) : 움직이는 방해물이나 “실시간”으로 길을 막는 문, 상자 등에 부착
	- Carve 옵션 활성화 -> 네비메쉬 표면에 실시간으로 구멍을 생성
		- 다른 에이전트들이 피해가도록 동적 지도 수정 

- 네비메쉬 링크(NavMeshLink)
	- 물리적으로 떨어진 곳을 연결해 AI가 점프나 낙하를 할 수 있게 도움
	- 사다리, 뛰어내리는 지형 등 

## 워크플로우

-  패키지 매니저에서 AI Navigation 설치
- 표면 베이킹
	- 빈 오브젝트 생성 -> NavMeshSurface 컴포넌트 추가 -> Bake 클릭 (바닥 영역 체크)
	
- 에이전트 배치
	- 이동 캐릭터에 NavMeshAgent 추가
	
- 스크립트 (컴포넌트) 제작
	- NavMeshAgent의 SetDestination으로 원하는 목적지 설정 밎 이동

# NavMeshSurface

- 네비메쉬 표면(NavMeshSurface)
	- 씬 전체 굽기 -> 특정 구역&특정 컴포넌트 단위의 네비메쉬 독립 제어
	- 내가 원하는 범위 내의 오브젝트와 내가 원하는 설정으로 네비메쉬를 구워주는 주체
	- 씬에 여러개 배치 가능하며, 각각의 서페이스는 다른 에이전트 크기에 맞춰 독립적인 레이어를 가질수 있음.

## 네비메쉬 요원(Agent) 컴포넌트

- 네비메쉬 위를 걸어다니는 대상에게 반드시 필요한 컴포넌트
- 단순히 목적지까지 가는 것 뿐만 아니라, 가속/감속, 회전하며 움직이는 다른 AI 동료들을 알아서 피해가기도 함
- 다만 NavMeshAgent 하나만 쓸 순 없고, 이 컴포넌트를 참조하는 사용자 정의 컴포넌트를 하나 만들어서 그 코드에서 더 세밀한 제어를 해야 함 (게임 실행 후 타겟 지정과 변경, 제자리 멈추기 등)

## NavMeshObstacle

네비메쉬 방해물(Obstacle) 컴포넌트
- 미리 구울 수 없는, 또는 게임 플레이 도중 만들어지는 방해물을 만들 때 사용하는 컴포넌트
	- Agent들이 경로 판단 시 이 방해물을 피해가야할 대상으로 인식하게 함
	- 게임 플레이 중 맵을 다시 베이킹하는 것은 무리가 있으므로, Obstacle을 사용해 특정 부분만 파내거나 우회

## NavMeshLink

- 끊어져 있는 두 내비메쉬 구역을 물리적으로 연결해 주는 '다리(Bridge)' 역할을 하는 컴포넌트
	- 끊어진 절벽이나 지붕(점프), 바닥에서 2층 가로등이나 사다리로 이어지는 경우 (올라가기)
	- 포탈이나 텔레포트 (순간이동)
