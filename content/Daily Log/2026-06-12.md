# 2026-06-12

## [심화반]

![[사진/Pasted image 20260612161941.png]]

### Client

- 서버에 접속하는 기기(ex. 게임에 접속한 기기)
- 입력 담당(서버에게 전송)
- 렌더링(서버에서의 응답을 받음)

### Server

- 계산
- 접속한 모든 클라이언트에게 동기화

### Network

- 클라이언트 - 서버 연결 및 데이터 전송
- Ping -> 클라이언트 - 서버 데이터 왕복 전송 시간
- 전송되는 데이터를 잘게 쪼갬 -> 패킷

![[사진/Pasted image 20260612164606.png]]

### 서버

- 렉 적음
- 안정성 높음
- 금액적 부담
- 배그, 롤 etc...

### 호스트

- 클라이언트 중 한 명을 서버로 사용
- 서버로 사용된 클라이언트 = 호스트
- 금액적 부담 없음
- 상황에 따라서 서버 모드 보다 안정적일 수 있음
- 호스트 종료시 모든 유저가 강제 접속 종료 됨.
- 스타크래프트 유즈맵, 마인크래프트 etc..

### 쉐어

- 클라우드 룸이 상태를 관리하고 클라이언트가 일부 권한을 나눠 가짐
