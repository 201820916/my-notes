
## 유니티 프로젝트 구조


수동 관리 ( 공유 )
- Assets : 개발에 필요한 모든 리소스가 저장됨.
- Packages : 프로젝트에 포함된 패키지의 **메타데이터**가 저장
	- 유니티 패키지 매니저를 통해 **설치한 패키지들의 정보**가 저장
- ProjectSettings : 프로젝트의 전반 설정 저장
	- 에디터, 빌드, 입력 설정 등

자동 관리 ( 개인 )
- Library : 유니티 엔진이 프로젝트 빌드, **실행 시 필요한 메타데이터와 캐시파일 저장**
- Logs : 유니티 에디터와 플레이어에서 생성되는 **로그 파일 저장**
- Temp : 유니티 작업 중 일시적 생성 파일들
- UserSettings : 개발자 개인의 데이터 설정 저장 **(개인적 사항이니 공유 X)**
