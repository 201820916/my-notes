
# 머테리얼

- 재질
	- 3D 오브젝트의 피부가 **시각적으로 어떻게 보여질지 결정**하는 에셋
	- 머테리얼이 없으면 아무 색이 없는 플라스틱 인형과 다를게 없음
	- 이 인형에 색과 질감을 추가
- 역할
	- 빛 관련 : 반사, 흡수, 투과
	- 질감 관련 : 금속성, 비금속성, 투명도, 발광

- 결과 산정 방식
	- 쉐이더
		- 머테리얼의 논리로 계산 공식과 같음
		- 빛, 색상조합, 조건별 조합 등 다양한 논리 처리 담당
		- 이 논리에는 수학적 연산과 텍스쳐로 받아오는 재료들이 모두 사용됨
	- 텍스쳐
		- 머테리얼에 들어가는 2D 이미지 파일(PNG, TGA)
			- 색상, 빛을 받을때의 울퉁불퉁함, 금속 텍스쳐, 알파 텍스쳐 등 다양한 텍스쳐 이용

# 텍스쳐

## 기본 색상 담당 : 알베도 =  베이스 컬러맵 = 디퓨즈맵
-  디퓨즈는 엄연히 “확산광”을 의미하는 단어
-  알베도 같이 텍스쳐의 기본적인 색상을 담당하는 맵을 디퓨즈로 부르는 경우도 있음
	- 엄연히 알베도가 맞음( 또는 알베도 외에 베이스컬러맵이라고 불러도 무관)

##  노말맵 : 눈속임용 빛

-  3D 모델링은 평평 ->  노말맵 추가 시 GPU는 노말맵의 가짜 기울기 정보를 확인
	- 기울어진 정도에 따라 빛 반사를 조절
	- EASY CHECK : 푸른색 텍스쳐 = 노말맵
