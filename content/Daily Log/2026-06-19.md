
# 머테리얼

- 재질
	- 3D 오브젝트의 피부가 **시각적으로 어떻게 보여질지 결정**하는 에셋
	- 머테리얼이 없으면 아무 색이 없는 플라스틱 인형과 다를게 없음
	- 이 인형에 색과 질감을 추가
- 역할
	- 빛 관련 : 반사, 흡수, 투과
	- 질감 관련 : 금속성, 비금속성, 투명도, 발광

- 결과 산정 방식
	- 쉐이더
		- 머테리얼의 논리로 계산 공식과 같음
		- 빛, 색상조합, 조건별 조합 등 다양한 논리 처리 담당
		- 이 논리에는 수학적 연산과 텍스쳐로 받아오는 재료들이 모두 사용됨
	- 텍스쳐
		- 머테리얼에 들어가는 2D 이미지 파일(PNG, TGA)
			- 색상, 빛을 받을때의 울퉁불퉁함, 금속 텍스쳐, 알파 텍스쳐 등 다양한 텍스쳐 이용

# 텍스쳐

## 기본 색상 담당 : 알베도 =  베이스 컬러맵 = 디퓨즈맵
-  디퓨즈는 엄연히 “확산광”을 의미하는 단어
-  알베도 같이 텍스쳐의 기본적인 색상을 담당하는 맵을 디퓨즈로 부르는 경우도 있음
	- 엄연히 알베도가 맞음( 또는 알베도 외에 베이스컬러맵이라고 불러도 무관)

##  노말맵 : 눈속임용 빛

-  3D 모델링은 평평 ->  노말맵 추가 시 GPU는 노말맵의 가짜 기울기 정보를 확인
	- 기울어진 정도에 따라 빛 반사를 조절
	- EASY CHECK : 푸른색 텍스쳐 = 노말맵

### 노말맵 제작 - 리토폴로지

3D 모델러가 **반드시 해야하는 작업**
- 고퀄리티 3D 모델을 단순한 메쉬로 외형의 큰 틀을 유지하되 면을 줄이는 작업
- 하이폴 메쉬, AI가 생성한 리소스를 그대로 사용하면 -> 작업 관련된 모두가 불편을 겪음


### 노말맵 제작 - 노말맵 베이킹

- 리토폴로지가 된 메쉬와 이전에 스컬핑한 고퀄리티 메쉬
	- 같이 켜둔 상태로 베이킹을 해서 노말맵을 추출


## 텍스쳐

### 알파맵

- Alpha Map
	- 어느 부분이 얼마나 투명할지 지정하는 흑백 마스크 또는 텍스쳐의 Alpha 채널
	- 1 : 완전 불투명
	- 0.1 - 0.9 : 반투명 (유리)
	- 0 : 완전 투명(숨겨짐)
- 컷아웃(Cutout) 또는 알파 클리핑(AlphaClipping)인 경우 기준점을 기준으로 0 or 1 처리 
	- 반투명(Transparancy)는 비용이 높음
	- 어쩔 수 없이 투명-불투명 처리가 필요한 경우 
		- 아예 셰이더 렌더링 모드에서 Opaque 항목에서 컷아웃 옵션을 지정하기도함

- 여전히 알파맵을 쓰지만, 텍스쳐에 반투명표현을 위한 0.1 ~ 0.9의 회색 값이 있음
	- 머테리얼의 Surface Option에서 Opaque의 Transparent를 설정
	- 단, 반투명은 비용이 높기 때문에 주의해야 함
	- 따라서 이런 경우 Dithered transparency texture를 사용해 Cutout으로 반투명을 표현하기도 함
