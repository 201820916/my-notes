## 헤더파일

### 입력&출력

- 무조건 string 형태로 입력과 출력이 진행된다.

### 조건문

- if
- else if
- else

```
int number = rand()%3
if ( number == 0 ) // number가 0이라면
{

}

else if ( number == 1) // 또
{

}

else
{

}
```

if - 1번 분기점
else if - 1번 분기점에 **부합하지 않을 경우** 2번 분기점
else - 1번과 2번 분기점에 **전부 부합하지 않는 경우**

Q. else if 대신 if 한번 더 써도 되는가?
```
int number = rand()%3
if ( number == 0 )
{

}

if ( number == 1)
{

}

if ( number == 2)
{

}
```

이 경우 첫 번째 if 조건이 성립되어도 두 번째, 세 번째 if문이 의미 없이 실행된다.


### 조건 선택문

```
int type = 0;

switch(type)
{
	case 0:
		...
		break;
	case 1:
		...
		break;
	
	case 2:
		...
		break;
}
```

switch문의 매개변수인 type의 값에 따라 서로 다른 결과를 나타낸다.


### enum

- 열거형
- 내부적으로는 숫자(정수)의 모음이나 이름표를 붙혀둔 사용자 자료형

```
enum WeaponType
{
	Sword, // 0
	Wand, // 1
	Gun // 2
}
```

각 원소에 값을 대입하여 번호를 설정할 수 있음

ex) Sword = 101 -> 101번으로 번호 설정


### 반복문

특정 조건이 끝날 때 까지 똑같은 행동을 반복하는 영역을 형성 할 때 사용

- for
```
int MonsterCount = 20;

for ( int i = 0 ; i < MonsterCount < i++ )
{
	GenMoster();
}
```

i < MonsterCount -> i가 MonsterCount보다 작다면 반복한다

When?

int i = 0 -> i가 0부터 시작하며
i++ -> 반복이 한번 실행되면 i의 값이 1씩 커진다

결론 : i가 0부터 시작, MonsterCount보다 작다면 반복을 실행함, 반복이 끝나면 i 값이 1 증가

- while
```
bool EndGame = false;

while(!EndGame)
{
	...
}
```

While은 매개변수가 true인 동안 무한히 반복된다.

특정 조건 ( if문 )에 break를 이용하거나 예시와 같이 bool형 타입을 이용하여 while을 종료할 수 있다.

## 다항식

```
int finalDamage = isCritical ? (baseDamage* 2) : baseDamage;
```

isCritical  -> true -> baseDamage\*2
		-> false -> baseDamage
