
## 2D Sprite

- 단순한 비트맵 이미지를 **유니티의 Sprite Renderer 컴포넌트가 그려낼 수 있도록** 세팅
- is not equal texture : 일반적인 텍스처의 의미는 3D 오브젝트에 입혀지는 포장지를 표현
- UI나 2D 애니메이션이 아닌 범주의 큰 이미지 : (2D) Texture라고 부름


| 구분      | Sprite                     | Texture                        |
| ------- | -------------------------- | ------------------------------ |
| 주요용도    | 버튼, 아이콘, 2D 캐릭터, 나인슬라이스 UI | 배경 일러스트, 웹 다운로드 이미지, 3D 모델링 스킨 |
| 핵심 컴포넌트 | Image, Sprite Renderer     | Raw Image, Material/Shader     |
| 메모리 효율  | 작고 반복되는 이미지에 최적화           | 큰 이미지 하나를 통째로 보여줄 때 유리         |

## Sprite Renderer

- 이미지를 씬 화면에 그려주는 역할, 색상, 좌우 반전 등 조작 가능
- Sorting Order : 이미지의 순서를 결정 **순서가 클수록 앞쪽에 렌더링**
- **UGUI의 Image는 Canvas 안에서 그려짐**
	- Sprite Renderer는 씬에 있음
	- 해당 게임 오브젝트가 카메라 영역안에 있으면 출력

## TileMap

- Grid와 Tilemap : 맵을 그리드 형태로 나누고 그 위에 타일을 깔아 맵을 구성하는 컴포넌트
- Tile palette : 타일들을 모아두고 브러시처럼 씬에 칠할 수 있게 해주는 에디터 툴
- Order in Layer로 뎁스 조절


## Rigid2D & Collider2D

- Rigidbody2D : **2D 객체에 중력 적용 & 물리 엔진 영향**
	- Dynamic : 중력+힘
	- Kinematic : 중력 무시 + 코드로 움직임
	- Static : 절대 움직이지 않음 -> 벽&바닥 추천, 연산 부하 거의 없음
	
- Collider2D : **객체의 충돌 영역을 정의**

## 충돌 처리

- OnCollisionEnter2D : 물리적으로 부딫히고 튕겨 나갈 때
- OnTriggerEnter2D : 물리적 저항 없이 영역 통과 & 이벤트만 발생 시킬 때

## 애니메이션

- 정지된 이미지를 연속으로 보여주여 움직이는 것 처럼 보이게 하는 영상기법
- In Game : 입력에 따라 즉각적으로 상태가 변하는 비선형적 특성
- In Unity : 매 프레임마다 미리 기록된 어떤 상태값을 지정된 게임 오브젝트에 반영

- Sprite Animation
	- 큰 한장의 이미지 로드 -> 일정 범위를 잘라서 Sprite 리소스 생성
	- 이를 애니메이션에 등록해 프레임화
	- SpriteRenderer의 이미지(Sprite 리소스)를 계속 교체함으로써 애니메이션 표현

- Spine
	- 3D 애니메이션의 Born 애니메이션 개념을 가져와 리소스 용량 아끼고 2D 표현 가능
	- Unity 2D Animation에서 스파인 관념을 도입하기 위해 많은 노력

- 리깅
	- 모델링에 뼈대를 할당해 본이 움직이면 설정한 값만큼 같이 따라올 수 있도록 설정
	- 본이 있어 가능한 표현
		- 캐릭터 사망시 축 늘어지게 -> 래그 돌 기법
		- 드레스나 코트 끝자락이 엔진의 물리법칙 대로 흔들거리게 -> 피지컬 본

### 애니메이션 표현에 필요한 요소들

- Animator
	- 애니메이션 재생 대상
	- Animator 컴포넌트
		- 코드와 컨트롤러를 이어주는 상태 제어 핵심 중재자
		- 하체와 상체의 움직임을 레이어의 가중치로 조절, 더 복잡한 표현 가능
		- 루트 모션

- AnimatorController
	- 상태머신을 설계, 특정 상황에서 어떤 클립을 재생할 지 결정
	- 애니메이션 논리 설계도
	- 수많은 객체가 필요로 하는 공통객체를 컨트롤러 한개로 해결 가능
	- 오버라이드 다형화 가능


- AnimationClip
	- 데이터 에셋, 애니메이션 리소스
	- 애니메이션 타입
		- 휴머노이드 : 인간형
		- 제네릭 : 비인간형 캐릭터를 위한 표준 방식
		- 레거시 : 과거 사용하던 방식
