
## 2D Sprite

- 단순한 비트맵 이미지를 **유니티의 Sprite Renderer 컴포넌트가 그려낼 수 있도록** 세팅
- is not equal texture : 일반적인 텍스처의 의미는 3D 오브젝트에 입혀지는 포장지를 표현
- UI나 2D 애니메이션이 아닌 범주의 큰 이미지 : (2D) Texture라고 부름


| 구분      | Sprite                     | Texture                        |
| ------- | -------------------------- | ------------------------------ |
| 주요용도    | 버튼, 아이콘, 2D 캐릭터, 나인슬라이스 UI | 배경 일러스트, 웹 다운로드 이미지, 3D 모델링 스킨 |
| 핵심 컴포넌트 | Image, Sprite Renderer     | Raw Image, Material/Shader     |
| 메모리 효율  | 작고 반복되는 이미지에 최적화           | 큰 이미지 하나를 통째로 보여줄 때 유리         |

## Sprite Renderer

- 이미지를 씬 화면에 그려주는 역할, 색상, 좌우 반전 등 조작 가능
- Sorting Order : 이미지의 순서를 결정 **순서가 클수록 앞쪽에 렌더링**
- **UGUI의 Image는 Canvas 안에서 그려짐**
	- Sprite Renderer는 씬에 있음
	- 해당 게임 오브젝트가 카메라 영역안에 있으면 출력

## TileMap

- Grid와 Tilemap : 맵을 그리드 형태로 나누고 그 위에 타일을 깔아 맵을 구성하는 컴포넌트
- Tile palette : 타일들을 모아두고 브러시처럼 씬에 칠할 수 있게 해주는 에디터 툴
- Order in Layer로 뎁스 조절


## Rigid2D & Collider2D

- Rigidbody2D : **2D 객체에 중력 적용 & 물리 엔진 영향**
	- Dynamic : 중력+힘
	- Kinematic : 중력 무시 + 코드로 움직임
	- Static : 절대 움직이지 않음 -> 벽&바닥 추천, 연산 부하 거의 없음
	
- Collider2D : **객체의 충돌 영역을 정의**

## 충돌 처리

- OnCollisionEnter2D : 물리적으로 부딫히고 튕겨 나갈 때
- OnTriggerEnter2D : 물리적 저항 없이 영역 통과 & 이벤트만 발생 시킬 때
