
## 알고리즘(개념)

- "문제를 해결하기 위한 논리적 단계"
- **완벽한 해답**을 찾기 보단 **고민하고 개선하는 방향**으로 알고리즘을 대하기

### 알고리즘의 5대 조건

- 입력 : 외부 제공 데이터가 0개 이상
- 출력 : 적어도 한 개 이상의 결과를 내야함
- 명확성 : 각 단계가 명확해야함.
- 유한성 : 무한 루프에 빠지지 않고 정상 종료 되어야함.
- 효율성 : 각 과정이 따라 할 수 있을 만큼 실행 가능해야함.

#### 알고리즘과 자료구조의 관계

- 자료구조 = 데이터의 효율적 **저장**
- 알고리즘 = 데이터의 효율적 **처리**
	- 연산 비용 = **시간 복잡도**
	- 임시 기억 비용 = **공간 복잡도**

#### 알고리즘의 종류

- 정렬
- 탐색
- 그래프

## 데이터 드리븐 기초

- 데이터 드리븐 : 객관적인 데이터 기반으로 의사결정을 내리는 방식
- 데이터 자체가 의사결정의 주체
- 데이터 관리 / 하드 코딩 X / 자료구조

1. 기획 내용을 보고 프로그래머가 데이터 설계도(스키마)를 구성
2. 스키마 참고하여 데이터 틀 구성 후 기획 직군에 전달
3. 기획 직군에서 엑셀 작성 후 Json 컨버팅 -> Git 업로드
4. 프로그래머는 해당 데이터의 설계를 기준으로 데이터 모델 클래스 작성
5. Json 데이터와 데이터 모델 클래스를 매핑 및 연동해서 게임 내 다양한 콘텐츠 개발

### 테이블

- 수많은 캐릭터들의 데이터 묶음 관리 -> 테이블
- 엑셀 데이터 -> Json OR XML 데이터 -> 데이터 모델
