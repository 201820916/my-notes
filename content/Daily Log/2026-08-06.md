

# MySQL

MySQL Server(**필수**) -> Git으로 비유하면 깃 패키지 그 자체

MySQL Workbench(**필수**) -> Git으로 비유 -> Fork처럼 Git 관련 활용 툴

Shell -> 콘솔창으로 명령어를 직접 쳐 DB 조작할 때 사용

Router -> 여러대의 MySQL 서버 사이에서 교통정리 해주는 미들웨어 서버


## Port

- 외부에서 실제로 송수신된 데이터들이 **올바른 프로그램**에 전달 될 수 있도록 하는 충돌 방지 역할
- 보안 역할 도 수행 ( 외부에서 특정 포트에 접근 하지 못하도록 통제 )
