## 게임 데이터의 작업 공정

- 기획 내용을 보고 프로그래머가 데이터의 설계도 스키마를 구서 
- 스키마를 참고해 엑셀로 기본적인 데이터의 틀을 구성 후 기획 직군에 토스
- 기획 직군에서 엑셀작성 후 JSON 컨버팅 -> Git 로드
- 프로그래머는 해당 데이터의 설계를 기준으로 데이터 모델 클래스로 작성
- JSON데이터 - 데이터 모델 클래스를 매핑-연동 -> 다양한 콘텐츠 개발

### 데이터 드리븐 - 테이블

- 우리가 UI로 볼 수 있는 모든 데이터들은 어떻게 되어 있는가?
- 수많은 캐릭터들의 데이터 묶음은 어떻게 관리되는가?
- -> Table로 관리 (Character Table, Skill Table etc...)

## 작업 공정(상세)

### 엑셀 데이터

- 기획 직군이 보통 작성
- 일반적으로 게임의 데이터로 이 엑셀 파일이 올라가지 않음

### JSON OR XML 데이터

- 엑셀 데이터가 한번 변환됨
- 서버와 클라이언트에서 모두 사용
- 게임의 데이터로 이 파일이 올라감

### 데이터 모델 ( Class OR Struct )

- DTO(데이터 전송 객체)
- 데이터 매칭 클래스
- JSON(혹은 XML)을 다른 형태로 대응 시키는 역할
