# 단어 정리

소프트웨어 - 기능, 디자인 등을 모아놓은 집합체 
하드웨어 - 소프트웨어를 실행하는 물리적 장치
프로그램 - 기능 구현을 위한 명령어 묶음

## 소프트웨어의 언어

인간
- 하이레벨 랭귀지
- 고수준 언어
* 일상적 인간의 언어

컴파일러 언어
* 사람이 사용하는 자연어와 비슷한 문법
* 컴퓨터는 이 언어를 이해 할 수 없음
* 컴파일러는 컴퓨터와 사람 간 통역을 맡음
* C, C++, C#, JAVA etc...
어셈블리어
*  복잡한 0,1 기계어를 사람이 조금 더 읽기 쉽게 기호로 바꿈
* 기계어 명령어와 1:1 대응
* 하드웨어 직접 제어, 메모리 세밀하게 조작

기계어
* 컴퓨터가 직접 읽고 이해할 수 있는 유일한 언어
* 0과 1로만 이루어진 이진코드
* 실행속도 빠르지만 사람이 읽거나 작성은 불가능
* CPU 아키텍처 마다 고유한 구조, 호환성 낮음

매니지드 언어
* 프로그램 실행과 메모리 관리를 특정 런타임 환경이 알아서 관리 해주는 언어
* C#, JAVA, Python, JavaScript etc...
* 자동 메모리 관리 : 가비지 컬렉터 내장 & 사용되지 않는 메모리 자동 회수
* 가상 머신 실행 : 중간언어로 한 번 변환된 후 가상머신 위에서 실행
* 높은 이식성과 안전성 : 다양한 환경에서 동일 동작 & 잘못된 접근 차단


## 운영체제

사용자가 컴퓨터를 쉽고 효율적으로 사용하도록 돕는 핵심 소프트웨어

컴퓨터 -> 하드웨어 -> 메모리, CPU etc...

ex) 윈도우, 안드로이드, IOS etc...


### 역할

자원 분배
- 한정된 자원을 효율적으로 사용하기 위해 개발된 기술
- 시간 분할 할당 : CPU처럼 한 번에 하나의 프로세스만 사용할 수 있는 자원을 프로세스들이 시간을 쪼개어 번갈아 가며 사용하게 하는 방식
* 공간 분할 할당 :  메모리처럼 물리적인 공간 자체를 여러 영역으로 나누어 여러 프로세스가 동시에 사용할 수 있도록 분배

스케줄링
* 공정한 자원 할당을 통해 특정 프로세스가 자원을 받지 못하는 현상을 방지
* 단위시간당 처리 프로세스 양을 늘리고 프로세스 교체 과정에서 낭비되는 자원  감소
* CPU 연산 위주 / 입출력 위주 작업을 적절히 섞어 균형 있는 사용 유도
* ex) 선입선출, 라운드로빈, 최단작업우선, 다단계 피드백 큐


## 유니티에서 사용하는 두가지 빌드 방식

mono
- C#을 중간 언어로 우선 변환
- **이후 게임이 실행되는 도중에 기기에 맞는 코드로 번역(JIT 방식)**
- 장점 : 빌드 속도 빠름
- 단점 : 런타임 성능 낮음

IL2CCP
- 중간 언어 변환
- **이후 C++ 코드로 2차 변환 -> 기계어로 완전히 컴파일 하는 AOR 방식**
- 장점 : 실행 속도와 성능이 뛰어남, 코드 보안성 높음
- 단점 : 빌드가 매우 오래걸림
