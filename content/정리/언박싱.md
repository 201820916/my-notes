박싱된 데이터를 원래 값 타입으로 다시 꺼내는 과정. 정확한 타입 캐스팅이 필요하다.

## 코드 예시

```csharp
object boxed = 10;
int number = (int)boxed;
```

## 이해를 돕는 설명

박싱할 때의 정확한 값 타입으로 꺼내야 하며 타입이 다르면 예외가 발생한다. object에 여러 타입을 섞어 담는 설계는 이런 오류를 만들기 쉽다.

## 더 깊이 이해하기

C#의 언박싱 문법이나 기능을 사용할 때는 컴파일 시점과 실행 시점 중 언제 의미가 결정되는지, 값 타입과 참조 타입에 어떻게 적용되는지, null·예외·반환값을 어떤 방식으로 처리하는지 함께 확인해야 한다. 문법을 짧게 만드는 것보다 호출하는 코드가 의도와 부작용을 분명히 이해할 수 있도록 사용하는 것이 중요하다.

## 적용할 때 확인할 점

간단한 정상 사례뿐 아니라 null, 범위 초과, 변환 실패와 같은 경계 조건을 확인한다. 공개 API에서 언박싱 관련 기능을 사용할 때는 호출자가 알아야 할 전제 조건과 반환 결과를 이름과 주석으로 표현하고, Unity 프로젝트가 사용하는 C# 버전에서 지원되는 문법인지 확인한다.
