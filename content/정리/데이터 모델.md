외부 데이터를 코드에서 사용하기 위해 만든 class 또는 struct 구조.

## 이해를 돕는 설명

외부 필드 이름과 코드 필드의 대응 관계를 정의한다. 저장용 모델과 실제 게임 로직 객체를 분리하면 데이터 형식 변경이 로직 전체로 퍼지는 것을 줄일 수 있다.

## 더 깊이 이해하기

데이터 모델 개념은 정의만 암기하기보다 목적, 구성 요소, 동작 과정, 다른 개념과의 경계를 함께 이해해야 한다. 실제 사례에서 어떤 문제를 해결하고 어떤 조건에서 한계가 드러나는지 비교하면 개념을 더 정확히 적용할 수 있다.

## 적용할 때 확인할 점

데이터 모델 개념을 실제로 적용할 때는 정상 사례와 실패 사례를 함께 만들고, 입력 조건과 결과를 기록한다. 비슷한 개념과 혼동하기 쉬운 경계를 비교하며, 선택에 따른 장점과 비용을 설명할 수 있는지 확인한다.
