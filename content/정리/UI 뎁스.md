UI가 화면에 그려지는 앞뒤 순서.

## 이해를 돕는 설명

UGUI에서는 같은 Canvas 안의 형제 순서가 기본 그리기 순서를 결정한다. Canvas가 다르면 Sorting Order와 렌더 모드도 함께 비교해야 한다.

## 더 깊이 이해하기

UI 뎁스 개념은 정의만 암기하기보다 목적, 구성 요소, 동작 과정, 다른 개념과의 경계를 함께 이해해야 한다. 실제 사례에서 어떤 문제를 해결하고 어떤 조건에서 한계가 드러나는지 비교하면 개념을 더 정확히 적용할 수 있다.

## 적용할 때 확인할 점

UI 뎁스 개념을 실제로 적용할 때는 정상 사례와 실패 사례를 함께 만들고, 입력 조건과 결과를 기록한다. 비슷한 개념과 혼동하기 쉬운 경계를 비교하며, 선택에 따른 장점과 비용을 설명할 수 있는지 확인한다.
