저장된 문자열이나 파일 데이터를 다시 코드 객체로 복원하는 과정.

## 코드 예시

```csharp
PlayerData data = JsonUtility.FromJson<PlayerData>(json);
```

## 이해를 돕는 설명

파일이 오래되었거나 필드가 누락될 수 있으므로 기본값과 버전 호환성을 고려해야 한다. 외부에서 받은 데이터는 신뢰하지 말고 유효성 검사를 거친다.

## 더 깊이 이해하기

역직렬화 관련 작업에서는 에디터의 원본 데이터, 빌드 결과물, 런타임에 로드된 인스턴스를 구분해야 한다. GUID와 참조 관계, 임포트 또는 직렬화 규칙, 로드·해제 시점, 플랫폼별 설정이 서로 연결된다. 데이터 구조나 배포 방식이 바뀔 수 있다면 버전 호환성과 누락 시 처리도 설계한다.

## 적용할 때 확인할 점

역직렬화 관련 데이터는 소유자와 해제 책임을 명확히 하고, 에디터에서는 정상이어도 빌드에서 누락될 가능성을 확인한다. 플랫폼별 압축과 경로, 대소문자, 비동기 실패, 데이터 버전 변경을 테스트하며 원본 .meta 파일과 GUID를 버전 관리에서 함께 보존한다.
