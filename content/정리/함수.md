특정 기능을 하나의 코드 블록으로 묶은 것. 반복 사용과 코드 분리에 유리하다.

## 이해를 돕는 설명

한 함수는 한 가지 책임만 갖도록 작게 나누면 이름만으로 의도를 파악하기 쉽다. 매개변수는 입력, 반환값은 결과로 생각하면 함수의 역할을 설계하기 편하다.

## 더 깊이 이해하기

C#의 함수 문법이나 기능을 사용할 때는 컴파일 시점과 실행 시점 중 언제 의미가 결정되는지, 값 타입과 참조 타입에 어떻게 적용되는지, null·예외·반환값을 어떤 방식으로 처리하는지 함께 확인해야 한다. 문법을 짧게 만드는 것보다 호출하는 코드가 의도와 부작용을 분명히 이해할 수 있도록 사용하는 것이 중요하다.

## 적용할 때 확인할 점

간단한 정상 사례뿐 아니라 null, 범위 초과, 변환 실패와 같은 경계 조건을 확인한다. 공개 API에서 함수 관련 기능을 사용할 때는 호출자가 알아야 할 전제 조건과 반환 결과를 이름과 주석으로 표현하고, Unity 프로젝트가 사용하는 C# 버전에서 지원되는 문법인지 확인한다.
