CPU(Central Processing Unit)는 명령어를 해석하고 프로그램의 일반적인 연산과 제어 흐름을 수행하는 중앙 처리 장치다. 게임에서는 입력, AI, 물리 준비, 스크립트 실행, 렌더링 명령 제출 등 다양한 작업을 담당한다.

## 주요 구성 요소

- **코어**: 독립적으로 명령을 실행할 수 있는 처리 단위다.
- **스레드**: 운영체제가 CPU 작업을 스케줄링하는 실행 흐름이다.
- **캐시**: 자주 사용하는 데이터를 빠르게 접근하기 위한 소형 고속 메모리다.
- **클럭**: 초당 동작 주기를 나타내지만 실제 성능은 구조와 작업 종류에도 좌우된다.

## 게임 성능과 CPU

Unity의 많은 게임 로직과 API는 메인 스레드에서 실행된다. 한 프레임의 메인 스레드 작업이 길어지면 GPU가 빨라도 프레임이 지연될 수 있다. 복잡한 AI, 과도한 물리 연산, 잦은 Instantiate, GC 할당, 많은 드로우 콜 제출 등이 CPU 병목을 만들 수 있다.

## 최적화 방향

Profiler에서 메인 스레드와 워커 스레드의 시간을 구분하고, 알고리즘과 데이터 접근을 먼저 개선한다. 병렬화는 작업이 서로 독립적이고 동기화 비용보다 계산량이 충분히 클 때 효과적이다. CPU 사용률 전체가 낮아도 메인 스레드 한 코어가 가득 차면 CPU 병목일 수 있다.
