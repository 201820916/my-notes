부모 클래스의 가상 메서드를 자식 클래스에서 새롭게 구현하는 것.

## 코드 예시

```csharp
class Enemy
{
    public virtual void Attack() { }
}

class Boss : Enemy
{
    public override void Attack() => Console.WriteLine("Boss attack");
}
```

## 이해를 돕는 설명

부모 메서드가 virtual 또는 abstract여야 하며 시그니처가 같아야 한다. 호출하는 변수의 타입이 부모여도 실제 인스턴스의 재정의된 메서드가 실행된다.
