부모 클래스의 가상 메서드를 자식 클래스에서 새롭게 구현하는 것.

## 코드 예시

```csharp
class Enemy
{
    public virtual void Attack() { }
}

class Boss : Enemy
{
    public override void Attack() => Console.WriteLine("Boss attack");
}
```

## 이해를 돕는 설명

부모 메서드가 virtual 또는 abstract여야 하며 시그니처가 같아야 한다. 호출하는 변수의 타입이 부모여도 실제 인스턴스의 재정의된 메서드가 실행된다.

## 더 깊이 이해하기

C#의 오버라이드 문법이나 기능을 사용할 때는 컴파일 시점과 실행 시점 중 언제 의미가 결정되는지, 값 타입과 참조 타입에 어떻게 적용되는지, null·예외·반환값을 어떤 방식으로 처리하는지 함께 확인해야 한다. 문법을 짧게 만드는 것보다 호출하는 코드가 의도와 부작용을 분명히 이해할 수 있도록 사용하는 것이 중요하다.

## 적용할 때 확인할 점

간단한 정상 사례뿐 아니라 null, 범위 초과, 변환 실패와 같은 경계 조건을 확인한다. 공개 API에서 오버라이드 관련 기능을 사용할 때는 호출자가 알아야 할 전제 조건과 반환 결과를 이름과 주석으로 표현하고, Unity 프로젝트가 사용하는 C# 버전에서 지원되는 문법인지 확인한다.
