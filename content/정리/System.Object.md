C#의 모든 타입이 기본적으로 상속받는 최상위 타입.

## 코드 예시

```csharp
object value = "hello";
Console.WriteLine(value.GetType()); // System.String
```

## 이해를 돕는 설명

값 타입도 object로 다룰 수 있지만 이 과정에서 박싱이 생길 수 있다. Equals, GetHashCode, ToString 같은 기본 동작은 모든 C# 타입에서 출발점이 된다.

## 더 깊이 이해하기

System.Object 개념은 정의만 암기하기보다 목적, 구성 요소, 동작 과정, 다른 개념과의 경계를 함께 이해해야 한다. 실제 사례에서 어떤 문제를 해결하고 어떤 조건에서 한계가 드러나는지 비교하면 개념을 더 정확히 적용할 수 있다.

## 적용할 때 확인할 점

System.Object 개념을 실제로 적용할 때는 정상 사례와 실패 사례를 함께 만들고, 입력 조건과 결과를 기록한다. 비슷한 개념과 혼동하기 쉬운 경계를 비교하며, 선택에 따른 장점과 비용을 설명할 수 있는지 확인한다.
