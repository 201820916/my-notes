C# 프로그램 실행에 필요한 런타임과 라이브러리 환경. 코드 실행, 메모리 관리, 기본 기능을 제공한다.

## 이해를 돕는 설명

문자열, 컬렉션, 파일 입출력 같은 기본 기능은 .NET 라이브러리에서 제공된다. Unity의 C# API와 .NET API는 함께 사용되지만 플랫폼과 Unity 버전에 따라 지원 범위가 다를 수 있다.

## 더 깊이 이해하기

시스템 관점에서 닷넷 프레임워크 개념은 프로그램의 한 계층만 설명하지 않는다. 소스 코드가 변환되고 운영체제가 실행 자원을 배분하며 CPU·GPU·메모리가 실제 작업을 처리하는 전체 흐름에서 위치를 파악해야 한다. 성능 문제는 평균 사용률만 보지 말고 병목 스레드, 대기 시간, 데이터 이동과 동기화 비용을 구분한다.

## 적용할 때 확인할 점

닷넷 프레임워크 관련 문제를 분석할 때는 추측으로 최적화하지 않고 프로파일러와 로그로 처리 시간, 메모리, 입출력, 대기 원인을 나눠 측정한다. 한 계층의 최적화가 다른 계층의 비용을 늘릴 수 있으므로 전체 프레임 또는 전체 실행 흐름에서 효과를 검증한다.
