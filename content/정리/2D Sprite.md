2D Sprite는 2D 게임에서 화면에 표시하는 이미지 리소스다. Unity에서는 원본 텍스처의 특정 영역과 피벗, 경계, Pixels Per Unit 등의 정보를 묶어 하나의 Sprite 에셋으로 관리한다.

## 핵심 설정

- **Sprite Mode**: 한 이미지에 하나의 스프라이트를 사용할 때는 `Single`, 여러 조각을 나눌 때는 `Multiple`을 사용한다.
- **Pixels Per Unit**: 이미지의 몇 픽셀을 월드 좌표 1단위로 볼지 결정한다. 값이 달라지면 같은 픽셀 크기의 이미지도 월드에서 보이는 크기가 달라진다.
- **Pivot**: 회전, 배치, 애니메이션의 기준점이다. 캐릭터는 보통 발밑, 회전하는 물체는 회전축에 맞춘다.
- **Filter Mode와 Compression**: 확대·축소 시 선명도와 메모리 사용량에 영향을 준다. 픽셀 아트는 일반적으로 Point 필터를 사용한다.

## 사용 방식

Sprite는 `SpriteRenderer`, UI의 `Image`, Tilemap, 애니메이션 클립 등에서 사용한다. 같은 텍스처를 사용하더라도 잘라낸 영역과 피벗 설정이 다르면 별개의 Sprite로 취급할 수 있다.

## 주의점

고해상도 원본을 그대로 사용하면 메모리 사용량이 커진다. 플랫폼별 Max Size와 압축 형식을 조정하고, 함께 그려지는 작은 이미지들은 Sprite Atlas로 묶어 드로우 콜과 텍스처 전환을 줄일 수 있다.
