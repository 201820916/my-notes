프로그램이 시작될 때 가장 먼저 실행되는 진입점.

## 이해를 돕는 설명

일반 C# 콘솔 프로그램은 Main에서 시작하지만 Unity 게임은 엔진이 진입점을 관리한다. Unity 스크립트에서는 Awake, Start 같은 라이프 사이클 메서드가 시작 지점 역할을 한다.

## 더 깊이 이해하기

C#의 Main 함수 문법이나 기능을 사용할 때는 컴파일 시점과 실행 시점 중 언제 의미가 결정되는지, 값 타입과 참조 타입에 어떻게 적용되는지, null·예외·반환값을 어떤 방식으로 처리하는지 함께 확인해야 한다. 문법을 짧게 만드는 것보다 호출하는 코드가 의도와 부작용을 분명히 이해할 수 있도록 사용하는 것이 중요하다.

## 적용할 때 확인할 점

간단한 정상 사례뿐 아니라 null, 범위 초과, 변환 실패와 같은 경계 조건을 확인한다. 공개 API에서 Main 함수 관련 기능을 사용할 때는 호출자가 알아야 할 전제 조건과 반환 결과를 이름과 주석으로 표현하고, Unity 프로젝트가 사용하는 C# 버전에서 지원되는 문법인지 확인한다.
