실제 데이터의 주소를 변수에 저장하는 타입. class, string, array 등이 대표적이다.

## 코드 예시

```csharp
var a = new List<int> { 1 };
var b = a;
b.Add(2);
Console.WriteLine(a.Count); // 2
```

## 이해를 돕는 설명

여러 변수가 같은 객체를 가리킬 수 있어 한쪽에서 객체 내용을 바꾸면 다른 쪽에서도 변화가 보인다. null일 가능성과 의도하지 않은 공유 변경을 주의해야 한다.

## 더 깊이 이해하기

C#의 참조 타입 문법이나 기능을 사용할 때는 컴파일 시점과 실행 시점 중 언제 의미가 결정되는지, 값 타입과 참조 타입에 어떻게 적용되는지, null·예외·반환값을 어떤 방식으로 처리하는지 함께 확인해야 한다. 문법을 짧게 만드는 것보다 호출하는 코드가 의도와 부작용을 분명히 이해할 수 있도록 사용하는 것이 중요하다.

## 적용할 때 확인할 점

간단한 정상 사례뿐 아니라 null, 범위 초과, 변환 실패와 같은 경계 조건을 확인한다. 공개 API에서 참조 타입 관련 기능을 사용할 때는 호출자가 알아야 할 전제 조건과 반환 결과를 이름과 주석으로 표현하고, Unity 프로젝트가 사용하는 C# 버전에서 지원되는 문법인지 확인한다.
