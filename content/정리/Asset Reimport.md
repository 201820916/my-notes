Asset Reimport는 Unity가 원본 에셋 파일을 다시 읽고 프로젝트 내부에서 사용하는 형식으로 변환하는 과정이다. 텍스처, 모델, 오디오 같은 파일을 변경하거나 Import Settings를 수정하면 해당 에셋과 관련된 산출물이 다시 생성된다.

## 발생 시점

- 프로젝트 외부 프로그램에서 원본 파일을 변경했을 때
- Texture Type, 압축, 모델 스케일 등의 Import Settings를 수정했을 때
- 임포터 버전이나 플랫폼 설정이 바뀌었을 때
- Inspector의 `Reimport` 또는 `Reimport All`을 실행했을 때

## 내부 동작

Unity는 파일의 GUID를 `.meta` 파일로 유지하면서 원본을 Library 폴더의 플랫폼용 데이터로 변환한다. 다른 에셋이 해당 파일에 의존하면 함께 다시 처리될 수 있다.

## 주의점

대형 텍스처와 모델, 많은 의존성을 가진 에셋은 리임포트 시간이 길다. `Reimport All`은 프로젝트 전체를 다시 처리하므로 문제 해결에 필요한 범위만 선택하는 것이 좋다. `.meta` 파일이 삭제되거나 새로 생성되면 GUID가 바뀌어 기존 참조가 끊길 수 있으므로 버전 관리에서 원본과 함께 보존해야 한다.
