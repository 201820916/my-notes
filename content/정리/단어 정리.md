- 빌드 방식
	- mono : C# -> 중간 언어
	- 이후 게임이 실행되는 도중에 기기에 맞는 코드로 번역( JIT 방식 )
	- 장점 : 빌드 속도 빠름
	- 단점 : 런타임 성능 낮음

	- IL2CCP : C# -> 중간 언어 -> C++ -> 기계어
	- 장점 : 실행 속도 & 성능 뛰어남, 코드 보안성 높음
	- 단점 : 빌드가 매우 오래걸림







## 변수
- 메모리의 4영역
- 코드 - 데이터 - 힙 - 스택

- 코드 : 작성한 소스 코드가 기계어로 변환되어 저장되는 영역 & READONLY

- 데이터 : 전역 변수와 static 변수가 저장되는 영역
	- 프로그램 시작 시 할당 되고 종료 시 소멸
	- 크기는 컴파일 타임에 결정
	
- 힙 : 프로그래머가 직접 할당 - 해체하는 동적 메모리 공간
	- C#에서는 GC가 자동으로 해제
	- 낮은 주소 -> 높은 주소 방향으로 자라며 계속 할당하면 메모리 누수 발생
	- 참조 타입

	- HEAP 메모리
	- 크기가 크거나 유동적인 데이터를 저장하기 위한 넓은 메모리 공간
	- 저장 데이터 : C#의 참조 타입 - class 객체, string, 배열 등
	- 동작 방식 : 개발자가 원할때(new 키워드 등) 필요한 만큼 동적 메모리 할당
	- 특징 : 메모리 크기 제한 X, 할당/해제 자동이지만 느림 

- 스택 영역 : 지역 변수, 매개 변수, 리턴 주소가 저장되는 영역
	- LIFO 방식 동작, 높은 주소 -> 낮은 주소 방향으로 자람
	- 함수 종료 시 해당 스택 프레임은 자동 해제
	- 값 타입
	
	- STACK 메모리
	- 임시 데이터들을 차곡차곡 쌓아두는 공간
	- 저장되는 데이터 : 매개변수, 지역변수, 값 타입 데이터
	- 동작 방석 : 후입선출(LIFO), 데이터 삽입(Push), 데이터 삭제(POP)
	- 특징 : 메모리 할당과 해제가 컴파일러에 의해 빠른 속도로 자동 수행됨, 크기 제한으로 큰 데이터는 불가능

## BIG-O 표기법

- 데이터 양이 늘어나면 -> 연산 횟수, 메모리 사용량 증가 -> 얼마나 급격하게 변화하는가 설명

## 박싱 / 언박싱

### 박싱
- 값 타입(스택에 저장)- > 참조 타입(힙에 저장)으로 변환하는 과정
- int, float, struct 등의 값을 object로 변환할 때 일어남
- 스택 메모리에 있던 값 타입 데이터가 힙 메모리 영역에 새롭게 할닫ㅇ
- 스택에는 힙 메모리를 가리키는 참조가 남음
- 특징 : 암시적 변환

```
int i = 123;
object o = i;
```

### 언박싱

- 반대로 참조타입(힙메모리) -> 다시 원래의 값 타입(스택메모리)로 되돌리는 과정
- 힙 영역에 저장된 객체에서 값을 꺼내옴
- 스택 영역의 값 타입 변수에 복사
- **정확히 일치하는 타입으로 명시적 캐스팅 필요**
-
```
object o = 123; // 박싱 
int j = (int) o; // 언박싱 (명시적 캐스팅 필수)
```

## 싱글턴

- 애플리케이션 전체에서 특정 클래스의 인스턴스를 단 하나만 생성하도록 보장
- 싱글턴 클래스의 세 가지 요소
	- private 생성자 - 외부에서 new로 인스턴스 생성을 막음
	- private static 인스턴스 필드 - 유일한 인스턴스를 저장
	- public static 프로퍼티 / 메서드 - 인스턴스 접근하는 단일 진입점

### 기본 구현

```
public class Singleton
{
    private static Singleton _instance;

    private Singleton() { } // 외부 생성 불가

    public static Singleton Instance
    {
        get
        {
            if (_instance == null) // ← 1. null인지 확인
                _instance = new Singleton(); // ← 2. null이면 새로 생성
            return _instance; // ← 3. 항상 인스턴스를 반환
        }
    }

    public void DoSomething()
    {
        Console.WriteLine("싱글턴 실행!");
    }
}

// 사용 예시
Singleton.Instance.DoSomething();
```

해당 코드는 \_instance 가 null인 경우에만 새 객체를 생성함

이미 존재하는 경우 기존 인스턴스를 반환함
