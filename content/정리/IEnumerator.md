C#에서 순차적으로 값을 반환하거나 유니티 코루틴을 구성할 때 사용하는 인터페이스.

## 코드 예시

```csharp
IEnumerator WaitThenPrint()
{
    yield return new WaitForSeconds(1f);
    Debug.Log("Done");
}
```

## 이해를 돕는 설명

일반 C#에서는 열거 동작을 표현하고 Unity에서는 yield 지점을 기준으로 실행을 나누는 코루틴에 사용된다. 반환형이 IEnumerator라고 해서 자동으로 실행되는 것은 아니며 StartCoroutine이 필요하다.

## 더 깊이 이해하기

C#의 IEnumerator 문법이나 기능을 사용할 때는 컴파일 시점과 실행 시점 중 언제 의미가 결정되는지, 값 타입과 참조 타입에 어떻게 적용되는지, null·예외·반환값을 어떤 방식으로 처리하는지 함께 확인해야 한다. 문법을 짧게 만드는 것보다 호출하는 코드가 의도와 부작용을 분명히 이해할 수 있도록 사용하는 것이 중요하다.

## 적용할 때 확인할 점

간단한 정상 사례뿐 아니라 null, 범위 초과, 변환 실패와 같은 경계 조건을 확인한다. 공개 API에서 IEnumerator 관련 기능을 사용할 때는 호출자가 알아야 할 전제 조건과 반환 결과를 이름과 주석으로 표현하고, Unity 프로젝트가 사용하는 C# 버전에서 지원되는 문법인지 확인한다.
