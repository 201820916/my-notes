같은 타입의 데이터를 연속된 공간에 저장하는 자료구조.

## 코드 예시

```csharp
int[] scores = { 10, 20, 30 };
Console.WriteLine(scores[0]);
```

## 이해를 돕는 설명

길이가 고정되고 인덱스로 빠르게 접근한다. 크기가 자주 변하면 List가 편하지만, 고정 데이터와 성능이 중요한 반복에서는 배열이 단순하고 효율적이다.

## 더 깊이 이해하기

배열 개념을 이해할 때는 데이터가 어떤 구조로 저장되고 각 연산이 어떤 순서로 수행되는지 추적해야 한다. 조회·삽입·삭제 비용, 추가 메모리, 입력 크기에 따른 증가율을 비교하면 특정 상황에 적합한 이유가 분명해진다. 이론적인 복잡도는 실제 입력 분포와 프로파일링 결과와 함께 판단한다.

## 적용할 때 확인할 점

작은 예제의 결과만 확인하지 말고 빈 입력, 하나의 요소, 중복 데이터, 매우 큰 입력을 테스트한다. 배열 방식을 선택한 이유를 주요 연산의 복잡도와 메모리 사용량으로 설명할 수 있어야 하며, 실제 환경에서는 측정 결과로 가정을 검증한다.
