Big-O 표기법은 입력 크기 `n`이 증가할 때 알고리즘의 실행 시간이나 추가 메모리 사용량이 어떤 비율로 증가하는지를 나타내는 점근적 표기법이다. 정확한 실행 시간을 계산하기보다 데이터가 커질 때의 확장성을 비교한다.

## 대표적인 증가율

- `O(1)`: 입력 크기와 무관한 상수 시간
- `O(log n)`: 입력 범위를 반복해서 줄이는 로그 시간
- `O(n)`: 모든 입력을 한 번씩 확인하는 선형 시간
- `O(n log n)`: 효율적인 비교 정렬에서 자주 나타나는 형태
- `O(n²)`: 두 입력 집합을 중첩해서 비교하는 형태
- `O(2ⁿ)`, `O(n!)`: 조합을 전부 탐색할 때 나타나는 급격한 증가

## 해석 방법

`3n² + 10n + 5`처럼 여러 항이 있으면 입력이 커질수록 가장 큰 영향을 주는 `n²`을 남겨 `O(n²)`으로 표현한다. 상수 계수는 생략하지만 실제 성능에서 상수가 중요하지 않다는 뜻은 아니다.

Big-O는 일반적으로 상한을 표현하며, 최선·평균·최악의 경우 중 어떤 상황을 분석하는지 함께 밝혀야 한다. 실제 프로그램에서는 캐시, 메모리 할당, 하드웨어, 입력 분포도 영향을 주므로 프로파일링 결과와 함께 판단하는 것이 좋다.
