클래스가 반드시 구현해야 하는 기능 목록을 정해두는 약속. 서로 다른 클래스를 같은 방식으로 다루게 해준다.

## 코드 예시

```csharp
interface IDamageable { void TakeDamage(int amount); }

class Enemy : IDamageable
{
    public void TakeDamage(int amount) { }
}
```

## 이해를 돕는 설명

구현이 아니라 필요한 기능에 의존하게 해 구체 클래스를 교체하기 쉬워진다. 플레이어와 적이 모두 IDamageable을 구현하면 공격 코드는 대상의 실제 클래스를 몰라도 된다.
