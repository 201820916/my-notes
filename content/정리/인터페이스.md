클래스가 반드시 구현해야 하는 기능 목록을 정해두는 약속. 서로 다른 클래스를 같은 방식으로 다루게 해준다.

## 코드 예시

```csharp
interface IDamageable { void TakeDamage(int amount); }

class Enemy : IDamageable
{
    public void TakeDamage(int amount) { }
}
```

## 이해를 돕는 설명

구현이 아니라 필요한 기능에 의존하게 해 구체 클래스를 교체하기 쉬워진다. 플레이어와 적이 모두 IDamageable을 구현하면 공격 코드는 대상의 실제 클래스를 몰라도 된다.

## 더 깊이 이해하기

C#의 인터페이스 문법이나 기능을 사용할 때는 컴파일 시점과 실행 시점 중 언제 의미가 결정되는지, 값 타입과 참조 타입에 어떻게 적용되는지, null·예외·반환값을 어떤 방식으로 처리하는지 함께 확인해야 한다. 문법을 짧게 만드는 것보다 호출하는 코드가 의도와 부작용을 분명히 이해할 수 있도록 사용하는 것이 중요하다.

## 적용할 때 확인할 점

간단한 정상 사례뿐 아니라 null, 범위 초과, 변환 실패와 같은 경계 조건을 확인한다. 공개 API에서 인터페이스 관련 기능을 사용할 때는 호출자가 알아야 할 전제 조건과 반환 결과를 이름과 주석으로 표현하고, Unity 프로젝트가 사용하는 C# 버전에서 지원되는 문법인지 확인한다.
