선언 시점이나 생성자에서만 값을 정할 수 있는 읽기 전용 필드.

## 코드 예시

```csharp
class Player
{
    private readonly int maxHp = 100;
}
```

## 이해를 돕는 설명

객체 자체를 다시 대입할 수 없다는 뜻이지, 참조한 List의 내부 항목까지 불변이라는 뜻은 아니다. 완전한 불변성이 필요하면 읽기 전용 컬렉션이나 불변 타입도 고려해야 한다.

## 더 깊이 이해하기

C#의 readonly 문법이나 기능을 사용할 때는 컴파일 시점과 실행 시점 중 언제 의미가 결정되는지, 값 타입과 참조 타입에 어떻게 적용되는지, null·예외·반환값을 어떤 방식으로 처리하는지 함께 확인해야 한다. 문법을 짧게 만드는 것보다 호출하는 코드가 의도와 부작용을 분명히 이해할 수 있도록 사용하는 것이 중요하다.

## 적용할 때 확인할 점

간단한 정상 사례뿐 아니라 null, 범위 초과, 변환 실패와 같은 경계 조건을 확인한다. 공개 API에서 readonly 관련 기능을 사용할 때는 호출자가 알아야 할 전제 조건과 반환 결과를 이름과 주석으로 표현하고, Unity 프로젝트가 사용하는 C# 버전에서 지원되는 문법인지 확인한다.
