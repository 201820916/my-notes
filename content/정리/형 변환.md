데이터를 다른 자료형으로 바꾸는 작업. 값 손실 가능성을 주의해야 한다.

## 코드 예시

```csharp
float speed = 3.8f;
int roundedDown = (int)speed;
Console.WriteLine(roundedDown); // 3
```

## 이해를 돕는 설명

작은 범위의 타입으로 바꾸면 값이 잘리거나 넘칠 수 있다. 사용자 입력이나 네트워크 문자열은 직접 캐스팅보다 TryParse처럼 실패를 처리할 수 있는 방식을 쓰는 편이 안전하다.

## 더 깊이 이해하기

C#의 형 변환 문법이나 기능을 사용할 때는 컴파일 시점과 실행 시점 중 언제 의미가 결정되는지, 값 타입과 참조 타입에 어떻게 적용되는지, null·예외·반환값을 어떤 방식으로 처리하는지 함께 확인해야 한다. 문법을 짧게 만드는 것보다 호출하는 코드가 의도와 부작용을 분명히 이해할 수 있도록 사용하는 것이 중요하다.

## 적용할 때 확인할 점

간단한 정상 사례뿐 아니라 null, 범위 초과, 변환 실패와 같은 경계 조건을 확인한다. 공개 API에서 형 변환 관련 기능을 사용할 때는 호출자가 알아야 할 전제 조건과 반환 결과를 이름과 주석으로 표현하고, Unity 프로젝트가 사용하는 C# 버전에서 지원되는 문법인지 확인한다.
