변수는 private로 유지하면서 유니티 인스펙터에서 값을 수정할 수 있게 하는 속성.

## 코드 예시

```csharp
[SerializeField] private float moveSpeed = 5f;
```

## 이해를 돕는 설명

캡슐화를 유지하면서 에디터에서 값을 연결할 수 있다. 인스펙터에 저장된 값이 코드의 필드 초기값보다 우선할 수 있다는 점을 주의한다.

## 더 깊이 이해하기

SerializeField 개념은 정의만 암기하기보다 목적, 구성 요소, 동작 과정, 다른 개념과의 경계를 함께 이해해야 한다. 실제 사례에서 어떤 문제를 해결하고 어떤 조건에서 한계가 드러나는지 비교하면 개념을 더 정확히 적용할 수 있다.

## 적용할 때 확인할 점

SerializeField 개념을 실제로 적용할 때는 정상 사례와 실패 사례를 함께 만들고, 입력 조건과 결과를 기록한다. 비슷한 개념과 혼동하기 쉬운 경계를 비교하며, 선택에 따른 장점과 비용을 설명할 수 있는지 확인한다.
