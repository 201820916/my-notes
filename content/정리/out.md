메서드가 여러 값을 반환할 때 사용하는 참조 전달 키워드. 메서드 안에서 반드시 값을 할당해야 한다.

## 코드 예시

```csharp
bool ok = int.TryParse("42", out int value);
Console.WriteLine(value); // 42
```

## 이해를 돕는 설명

TryParse 패턴처럼 성공 여부와 결과값을 함께 돌려줄 때 자주 사용한다. C#의 튜플 반환을 쓰면 여러 결과의 이름을 더 명확하게 표현할 수도 있다.

## 더 깊이 이해하기

C#의 out 문법이나 기능을 사용할 때는 컴파일 시점과 실행 시점 중 언제 의미가 결정되는지, 값 타입과 참조 타입에 어떻게 적용되는지, null·예외·반환값을 어떤 방식으로 처리하는지 함께 확인해야 한다. 문법을 짧게 만드는 것보다 호출하는 코드가 의도와 부작용을 분명히 이해할 수 있도록 사용하는 것이 중요하다.

## 적용할 때 확인할 점

간단한 정상 사례뿐 아니라 null, 범위 초과, 변환 실패와 같은 경계 조건을 확인한다. 공개 API에서 out 관련 기능을 사용할 때는 호출자가 알아야 할 전제 조건과 반환 결과를 이름과 주석으로 표현하고, Unity 프로젝트가 사용하는 C# 버전에서 지원되는 문법인지 확인한다.
