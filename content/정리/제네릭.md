타입을 나중에 지정할 수 있게 만든 문법. 타입 안정성과 재사용성을 높인다.

## 코드 예시

```csharp
List<string> names = new() { "Alice", "Bob" };
Console.WriteLine(names[0]);
```

## 이해를 돕는 설명

타입별로 같은 코드를 반복하지 않으면서도 컴파일 단계의 타입 검사를 유지한다. List<T>, Dictionary<TKey,TValue>와 공용 팩토리에서 대표적으로 사용된다.

## 더 깊이 이해하기

C#의 제네릭 문법이나 기능을 사용할 때는 컴파일 시점과 실행 시점 중 언제 의미가 결정되는지, 값 타입과 참조 타입에 어떻게 적용되는지, null·예외·반환값을 어떤 방식으로 처리하는지 함께 확인해야 한다. 문법을 짧게 만드는 것보다 호출하는 코드가 의도와 부작용을 분명히 이해할 수 있도록 사용하는 것이 중요하다.

## 적용할 때 확인할 점

간단한 정상 사례뿐 아니라 null, 범위 초과, 변환 실패와 같은 경계 조건을 확인한다. 공개 API에서 제네릭 관련 기능을 사용할 때는 호출자가 알아야 할 전제 조건과 반환 결과를 이름과 주석으로 표현하고, Unity 프로젝트가 사용하는 C# 버전에서 지원되는 문법인지 확인한다.
