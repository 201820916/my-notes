객체의 상태에 따라 행동을 분리하는 패턴.

## 코드 예시

```csharp
interface IState { void Tick(); }
IState currentState = new IdleState();
currentState.Tick();
```

## 이해를 돕는 설명

Idle, Chase, Attack의 진입·실행·종료 로직을 상태별로 나누면 거대한 조건문을 줄일 수 있다. 상태 수와 전환이 매우 많아지면 행동트리나 계층형 FSM도 고려한다.

## 더 깊이 이해하기

AI 의사결정 흐름에서 상태 패턴(FSM) 요소가 맡는 역할을 이해해야 한다. 평가 주기, 성공·실패·진행 상태, 우선순위, 중단 시 정리 동작을 함께 정의하면 같은 상황에서 항상 예측 가능한 결과를 만들 수 있다. 감지나 경로 계산처럼 비용이 큰 처리는 매 프레임 무조건 수행하기보다 주기 조절과 캐싱을 고려한다.

## 적용할 때 확인할 점

AI 로직에 적용할 때는 상태 패턴(FSM) 요소의 시작 조건과 종료 조건을 명시하고, 대상 소실·피격·상위 우선순위 변경처럼 실행 도중 발생하는 예외 상황을 처리한다. 디버깅 화면이나 로그에 현재 상태와 전환 원인을 남기면 복잡한 행동 흐름을 추적하기 쉽다.
