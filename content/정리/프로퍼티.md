필드 값을 안전하게 읽고 쓰기 위한 C# 문법. get/set으로 접근을 제어한다.

## 코드 예시

```csharp
class Player
{
    public int Hp { get; private set; } = 100;
}
```

## 이해를 돕는 설명

외부에는 값처럼 보이지만 내부에서 검증이나 알림 로직을 넣을 수 있다. 단순 필드 공개보다 변경 권한을 세밀하게 제한할 수 있다.

## 더 깊이 이해하기

C#의 프로퍼티 문법이나 기능을 사용할 때는 컴파일 시점과 실행 시점 중 언제 의미가 결정되는지, 값 타입과 참조 타입에 어떻게 적용되는지, null·예외·반환값을 어떤 방식으로 처리하는지 함께 확인해야 한다. 문법을 짧게 만드는 것보다 호출하는 코드가 의도와 부작용을 분명히 이해할 수 있도록 사용하는 것이 중요하다.

## 적용할 때 확인할 점

간단한 정상 사례뿐 아니라 null, 범위 초과, 변환 실패와 같은 경계 조건을 확인한다. 공개 API에서 프로퍼티 관련 기능을 사용할 때는 호출자가 알아야 할 전제 조건과 반환 결과를 이름과 주석으로 표현하고, Unity 프로젝트가 사용하는 C# 버전에서 지원되는 문법인지 확인한다.
