객체가 특정 타입과 호환되는지 확인하는 키워드.

## 코드 예시

```csharp
object value = "text";
if (value is string text)
    Console.WriteLine(text.Length);
```

## 이해를 돕는 설명

타입 확인과 변수 선언을 한 번에 하는 패턴 매칭을 사용할 수 있다. 상속 구조에서 실제 타입별 행동이 자주 필요하다면 다형성으로 옮길 수 있는지도 살펴볼 만하다.

## 더 깊이 이해하기

C#의 is 문법이나 기능을 사용할 때는 컴파일 시점과 실행 시점 중 언제 의미가 결정되는지, 값 타입과 참조 타입에 어떻게 적용되는지, null·예외·반환값을 어떤 방식으로 처리하는지 함께 확인해야 한다. 문법을 짧게 만드는 것보다 호출하는 코드가 의도와 부작용을 분명히 이해할 수 있도록 사용하는 것이 중요하다.

## 적용할 때 확인할 점

간단한 정상 사례뿐 아니라 null, 범위 초과, 변환 실패와 같은 경계 조건을 확인한다. 공개 API에서 is 관련 기능을 사용할 때는 호출자가 알아야 할 전제 조건과 반환 결과를 이름과 주석으로 표현하고, Unity 프로젝트가 사용하는 C# 버전에서 지원되는 문법인지 확인한다.
