클래스를 바탕으로 실제 메모리에 생성된 객체.

## 코드 예시

```csharp
Player player = new Player();
player.Jump();
```

## 이해를 돕는 설명

같은 클래스로 만든 인스턴스라도 각자 다른 체력과 위치를 가질 수 있다. static 멤버만 모든 인스턴스가 함께 공유한다.

## 더 깊이 이해하기

인스턴스 개념은 정의만 암기하기보다 목적, 구성 요소, 동작 과정, 다른 개념과의 경계를 함께 이해해야 한다. 실제 사례에서 어떤 문제를 해결하고 어떤 조건에서 한계가 드러나는지 비교하면 개념을 더 정확히 적용할 수 있다.

## 적용할 때 확인할 점

인스턴스 개념을 실제로 적용할 때는 정상 사례와 실패 사례를 함께 만들고, 입력 조건과 결과를 기록한다. 비슷한 개념과 혼동하기 쉬운 경계를 비교하며, 선택에 따른 장점과 비용을 설명할 수 있는지 확인한다.
