사람이 읽기 쉬운 문법으로 작성한 코드를 컴퓨터가 실행 가능한 형태로 번역해서 사용하는 언어. C, C++, C#, Java 등이 있다.

## 이해를 돕는 설명

작성한 코드는 컴파일 과정에서 문법 오류와 타입 오류를 먼저 검사받는다. C#은 보통 IL로 컴파일된 뒤 런타임이나 IL2CPP를 통해 실제 기계어로 실행된다.

## 더 깊이 이해하기

시스템 관점에서 컴파일러 언어 개념은 프로그램의 한 계층만 설명하지 않는다. 소스 코드가 변환되고 운영체제가 실행 자원을 배분하며 CPU·GPU·메모리가 실제 작업을 처리하는 전체 흐름에서 위치를 파악해야 한다. 성능 문제는 평균 사용률만 보지 말고 병목 스레드, 대기 시간, 데이터 이동과 동기화 비용을 구분한다.

## 적용할 때 확인할 점

컴파일러 언어 관련 문제를 분석할 때는 추측으로 최적화하지 않고 프로파일러와 로그로 처리 시간, 메모리, 입출력, 대기 원인을 나눠 측정한다. 한 계층의 최적화가 다른 계층의 비용을 늘릴 수 있으므로 전체 프레임 또는 전체 실행 흐름에서 효과를 검증한다.
