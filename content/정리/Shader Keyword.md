셰이더 내부 기능을 켜고 끄는 옵션 이름

- 색상&강도 조정
- 기능 사용 여부
- 텍스처 자체를 지정
- etc...


IF 하나의 셰이더가 다음 키워드를 가진다면 키워드에 따라 서로 다른 Shader Variant가 만들어짐.
- \_NORMALMAP
- \_EMISSION
- \_ALPHATEST_ON

## 코드 예시

```hlsl
#pragma shader_feature _NORMALMAP

#if defined(_NORMALMAP)
    // 노말맵을 사용하는 경로
#endif
```

## 이해를 돕는 설명

키워드는 런타임 if문과 달리 필요한 코드 조합을 별도 Variant로 컴파일할 수 있다. 키워드 조합이 늘면 빌드 시간과 메모리가 폭증할 수 있으므로 범위를 관리해야 한다.

## 더 깊이 이해하기

렌더링에서 Shader Keyword 개념은 화면 품질뿐 아니라 CPU의 렌더링 명령 제출, GPU 연산량, 텍스처와 버퍼 메모리, 메모리 대역폭에 영향을 줄 수 있다. 같은 결과라도 해상도, 오브젝트 수, 머테리얼 수, 투명도와 오버드로우에 따라 비용이 달라지므로 Frame Debugger와 GPU Profiler로 실제 병목을 확인해야 한다.

## 적용할 때 확인할 점

품질 설정은 대표 기기에서 비교하고, Shader Keyword 기능 적용 전후의 드로우 콜, 삼각형·정점 수, 셰이더 실행 시간, VRAM 사용량을 측정한다. 에디터 화면만으로 판단하지 말고 실제 빌드와 목표 해상도에서 시각적 오류와 성능을 함께 검증한다.
