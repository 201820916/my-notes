
# Network Object

- 고유 식별자(ID) 부여
	- 예시) 같은 공간에 있는 두 플레이어가 A라는 몬스터를 보고 있음
		- 두 A 몬스터는 같은 몬스터라고 엔진과 서버는 인지하고 있어야함 
		- A 몬스터에 변화가 일어나면 두 플레이어가 보고 있는 A 몬스터에 동일한 변화
		
- 권한 관리
	- 하나의 체스말이 됨.
		- 멀티 플레이 게임의 핵심 -> 누가 이 오브젝트를 조종/관리/상태 등을 결정하는가?
			- 상태 권한 : 체력, 직업, 위치 값
			- 입력 권한 : 누가 이 오브젝트를 마우스나 키보드로 입력을 넣을 수 있는가?
		
- 네트워크 생명주기 관리 (Spawn / DeSpwan)
	- 유니티의 동적 생성 Instantiate() -> 이건 내 화면에서만 보이고 다른 클라이언트에서는 보이지 않음
		- 해당 컴포넌트를 사용(예시 : runner.Spawn())하면 모두에게 보임
		
-  NetworkBehaviour의 컨테이너
	- Fusion에서 데이터 동기화, 위치 맞추기 
		- NetworkBehaviour 상속 받는 형태로 사용이 되어야 함
		- 상속 받으려면? -> Network Object 필요
