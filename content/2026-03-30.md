
## Unsigned

Unsigned? -> 부호를 붙일 수 없다!

int = -21억 ~ +21억
**Unsigned** int = 0 ~ 21억

Usigned int를 연산용으로? -> 생각해봐야함
Usigned int를 데이터 관리 및 표현 목적으로는? -> Good

## 형변환

```
float currentHp = 95.7f;  
float maxHp = 100.0f;

// 화면에 출력 될 값으로 3.33333333333333333333은 바람직 한가? -> 그렇지 않음
// 형 변환 필요함.
// 버림, 반올림, 올림 etc.. 처리
// BUT 반올림, 올림은 법적인 문제을 야기 할 수 있음

int displayHp = currentHp;

// 해당 코드는 가능한가? -> 불가능
// C++ -> 자동 형변환 지원
// C# -> 자동 형변환 미지원, 명시적 형변환 필요

int displayHp = (int)currentHp;
Console.WriteLine(displayHp);
// 해당 코드는 가능한가? -> 가능
// BUT 일부 값이 소실 될 수 있음.


// 반대로 소수점이 필요한 경우
int currentExp = 250;  
int requiredExp = 1000;  
  
float progress = (float)currentExp / requiredExp;  
// 정수 / 정수 = 정수(0)가 되므로, 하나를 float으로 형변환  
  
Console.WriteLine($"상황 2 - 진행률: {progress * 100}%");

// MEMO : 가장 좋은 설계는 형변환을 최대한 자제한 설계


```


## 제어문

### IF문
```
int gold = 100;  
if (gold >= 100)  
{  
	Console.WriteLine("아이템 구매 가능");  
}  

else if ( gold >= 100 && [조건 2])
// 같은 조건이 2개 있을 경우 묶는 것이 좋다.
// 3개 이상이면 무조건 묶기
// else if 제거 -> if 조건에 [&& 조건2] 삽입

else  
{  
	Console.WriteLine("골드 부족");  
}
// else는 필수인가? -> X
// if (gold >= 100)  에서 괄호 안의 값은 bool 값인가? -> O
```


### SWITCH
```
int level = 1;
switch (level)  
{  
	case 1: Console.WriteLine("초보"); break;  
	case 2: Console.WriteLine("중수"); break;  
	default: Console.WriteLine("고수"); break; // level 1, 2가 아닌 모든 경우
}
// switch에 int, string, enum 등 다양한 형태의 변수 가능
```

#### 메모
