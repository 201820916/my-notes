# 성훈의 노트

알고리즘 문제 풀이, 개념 정리, 일상 학습 기록을 차분하게 쌓아두는 개인 지식 저장소입니다.

> 오늘 배운 것과 다시 봐야 할 것을 한곳에 모아, 다음 공부가 더 가볍게 시작되도록 정리합니다.

## 바로가기

- [[Daily Log]]  
  날짜별 학습 기록과 회고를 남기는 공간
- [[정리]]  
  개념, 용어, 문법, 아이디어를 다시 찾기 쉽게 묶어두는 공간
- [[문제 풀이]]  
  알고리즘 문제 접근 방식과 풀이 과정을 정리하는 공간

## 학습 흐름

1. 매일 배운 내용을 짧게 기록합니다.
2. 반복해서 나오는 개념은 따로 정리합니다.
3. 문제 풀이는 접근 방식, 실수, 개선점을 함께 남깁니다.

## 최근 포커스

- 알고리즘 풀이 패턴 정리
- 헷갈리는 개념을 짧은 노트로 분리
- Daily Log를 통해 공부 흐름 추적
